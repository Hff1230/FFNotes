|------|------|
| ✅ **文件上传** | 支持 .cdr 格式文件上传 |

| ✅ **响应式设计** | 支持桌面和移动设备 |

**■ 🚀 使用说明**

**▍ 方法一：在线转换查看（推荐）**

由于CDR是CorelDRAW专有格式，浏览器无法直接显示，推荐以下流程：

```
1. 打开 H5 查看器 (cdr-viewer.html)
2. 上传 CDR 文件
3. 选择查看方式：
   ├─ 在线转换（使用转换工具）
   ├─ 下载后用CorelDRAW打开
   └─ 转换为SVG/PDF/PNG
4. 在预览区域查看转换结果
```

**■ 📋 使用流程**

**▍ 步骤1：打开查看器**

```bash
在浏览器中打开：AI库/图片处理/cdr-viewer.html
```

**▍ 步骤2：上传CDR文件**

**方式A：点击上传**

2. 放到上传区域

| 选项 | 说明 |

| **📥 下载文件** | 下载到本地用CorelDRAW打开 |
| **🌐 在线转换** | 提供在线转换网站链接 |
| **📖 查看指南** | 显示详细的查看和转换方法 |
| **🗑️ 删除** | 从列表中移除 |

**▍ 步骤4：查看转换结果**

- 如果文件是SVG/PDF/PNG格式，可以直接预览
- CDR文件需要先转换

**■ ⚠️ 注意事项**

**▍ 限制说明**

1. **浏览器限制**
   - CDR是专有格式，浏览器无法原生解析
   - 需要转换为SVG/PDF/PNG才能在浏览器中显示
   - 本查看器主要用于文件管理和转换引导

2. **文件安全性**
   - 本工具纯客户端运行，不涉及服务器
   - 文件不会上传到任何服务器
   - 所有处理都在本地完成

3. **隐私保护**
   - 不收集用户数据
   - 不记录文件信息
   - 完全离线可用

**▍ 常见问题**

| 问题 | 解决方案 |
|------|---------|
| 文件无法上传 | 检查文件格式和大小 |

| 转换后质量下降 | 使用专业软件（CorelDRAW） |
| 移动端无法打开 | 使用专业App或在线工具 |
