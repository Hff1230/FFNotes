## 1. 模块概述

出牌规则模块负责判断玩家出牌的合法性、牌型识别和大小比较，是游戏公平性的核心保障。

**重要说明**：本项目使用2副牌（108张），**没有炸弹概念**。

---

## 2. 牌型定义

**重要**：2副牌的80分只有以下牌型，**没有三张、没有炸弹**。

### 2.1 基础牌型

| 牌型 | 描述 | 示例 | 点数要求 |
|------|------|------|----------|
| 单张 | 任意一张牌 | ♠5 | 无 |
| 对子 | 两张及以上相同点数 | ♠5♥5、♠3♥3♦3♣3（4张） | ≥2张相同点数 |

**对子说明**：
- 2张同点数是对子
- 3张同点数也是对子（出其中2张）
- 4张同点数也是对子（可出2张或4张）

### 2.2 连续牌型（拖拉机）

| 牌型 | 描述 | 示例 | 条件 |
|------|------|------|------|
| 连对/拖拉机 | 连续的对子 | 3344、445566、7788991010 | 至少2对连续点数 |

**连续规则说明：**
- 点数必须连续：如3344、4455、5566等
- 不跨级牌：如打2时，AA22不算连对（A和2之间隔了级牌）
- 主牌不参与连对：主花色的牌不能组成连对

**连对示例：**
```
合法连对：  3344、445566、7788991010、JJQQKK
非法连对：  2233（打2时2是级牌）、AAKK（不连续）
```

### 2.3 特殊牌

| 牌 | 描述 | 大小规则 |
|-----|------|----------|
| 大王 | 红色Joker | 最大单牌 |
| 小王 | 黑色Joker | 次大单牌 |
| 级牌 | 当前级别的牌 | 主花色级牌 > 其他花色级牌 |

### 2.4 甩牌

当玩家手中有某花色的**最大牌组合**时，可以一次性打出。

**甩牌条件：**
- 确定该牌型在该花色中最大（其他三家都没有更大的）
- 甩牌失败则出最小的牌，并扣分处罚

## 3. 牌型大小规则

### 3.1 主牌定义

```
主牌包括：
1. 大小王（常主）
2. 级牌（如打2时，所有花色的2都是级牌）
3. 主花色的所有牌

主牌大小顺序：
大王 > 小王 > 主花色级牌 > 其他花色级牌 > 主花色A > K > Q > J > 10 > ... > 3
```

### 3.2 副牌大小

```
副牌大小顺序（以♠为例，非主花色时）：
A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3 > 2

注意：级牌在副花色中仍然是级牌，但小于主花色级牌
```

### 3.3 比较规则

| 场景 | 规则 |
|------|------|
| 同花色同牌型 | 比较最大那张牌的点数 |
| 主牌 vs 副牌 | 主牌大 |
| 不同副花色 | 无法直接比较，先出者领出 |
| 同为对子 | 比较对子点数 |
| 同为连对 | 比较连对中最大对子的点数 |

## 4. 跟牌规则（核心）

### 4.1 基本原则

**必须跟同牌型！** 首家出什么牌型，其他玩家必须跟同样牌型。

### 4.2 详细规则

```
1. 首家出单张
   - 有同花色必须跟同花色单张
   - 无同花色可出其他花色单张或主牌

2. 首家出对子
   - 有同花色对子必须跟同花色对子
   - 无同花色对子，但有同花色单张：
     - 必须先出完同花色单张（不能直接出其他花色对子）
   - 完全没有该花色，可出其他花色对子或主牌对子

3. 首家出连对（拖拉机）
   - 有同花色连对必须跟同花色连对
   - 有同花色对子但凑不够连对：
     - 必须先拆对子出（不能跳过）
   - 完全没有该花色，可出其他花色连对或主牌连对
```

### 4.3 跟牌流程图

```
┌─────────────────────────────────────┐
│         判断首家出牌牌型             │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│     检查是否有同花色的同牌型         │
│     （对子→对子，连对→连对）         │
└─────────────────┬───────────────────┘
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
    【有】               【没有】
        │                   │
        ▼                   ▼
  必须跟同牌型      检查是否有该花色
                        │
              ┌─────────┴─────────┐
              ▼                   ▼
          【有】               【没有】
              │                   │
              ▼                   ▼
        必须先出该花色      可出任意牌型
        （拆开出）          （包括主牌）
```

## 5. 功能清单

### F-012: 合法出牌判断

| 项目 | 内容 |
|------|------|
| 功能ID | F-012 |
| 优先级 | P0 |
| 描述 | 判断玩家出的牌是否符合规则 |

**判断逻辑：**

```javascript
function isValidPlay(handCards, playedCards, leadCards, trumpSuit, currentLevel) {
  // 1. 检查是否拥有这些牌
  if (!ownsCards(handCards, playedCards)) return { valid: false, reason: '没有这些牌' };

  // 2. 如果是首出，检查牌型是否合法
  if (!leadCards) {
    const cardType = identifyCardType(playedCards, currentLevel);
    return { valid: cardType.valid, cardType };
  }

  // 3. 获取首出牌型
  const leadType = identifyCardType(leadCards, currentLevel);
  const playType = identifyCardType(playedCards, currentLevel);

  // 4. 检查牌型是否匹配（对子对对子，连对对连对）
  if (!matchCardType(leadType, playType)) {
    // 检查是否是因为没有该牌型
    const hasRequiredType = checkHasCardType(handCards, leadType, leadCards.suit);
    if (hasRequiredType) {
      return { valid: false, reason: '必须跟相同牌型' };
    }
  }

  // 5. 检查花色跟牌规则
  const leadSuit = getLeadSuit(leadCards);
  const suitCheck = checkSuitFollow(handCards, playedCards, leadSuit, leadType);

  return suitCheck;
}

// 检查花色跟牌
function checkSuitFollow(handCards, playedCards, leadSuit, leadType) {
  const sameSuitCards = filterBySuit(handCards, leadSuit);

  // 有该花色的牌
  if (sameSuitCards.length > 0) {
    // 检查是否有该花色的同牌型
    const hasSameType = hasCardTypeInSuit(sameSuitCards, leadType);

    if (hasSameType) {
      // 必须出该花色的同牌型
      if (!isSameSuit(playedCards, leadSuit)) {
        return { valid: false, reason: '有同花色同牌型必须跟' };
      }
      if (!matchCardType(leadType, identifyCardType(playedCards))) {
        return { valid: false, reason: '必须跟相同牌型' };
      }
    } else {
      // 没有同牌型，必须先出该花色的牌（拆开出）
      if (!isSameSuit(playedCards, leadSuit)) {
        return { valid: false, reason: '有该花色必须先出' };
      }
    }
  }

  return { valid: true };
}
```

**验收标准：**
- [ ] 有同花色同牌型必须跟
- [ ] 有同花色但无同牌型，必须先出该花色
- [ ] 无该花色可出任意牌
- [ ] 牌型必须合法
- [ ] 手牌必须包含所出的牌

**依赖：** F-010

**风险：** 边界情况处理复杂

### F-013: 牌型识别

| 项目 | 内容 |
|------|------|
| 功能ID | F-013 |
| 优先级 | P0 |
| 描述 | 识别玩家出的牌属于什么牌型 |

**识别算法：**

```javascript
function identifyCardType(cards, currentLevel) {
  if (cards.length === 0) return { valid: false, reason: '没有牌' };

  // 按点数分组
  const groups = groupByRank(cards);
  const ranks = Object.keys(groups);

  // 单张
  if (cards.length === 1) {
    return { valid: true, type: 'single', rank: cards[0].rank, cards };
  }

  // 检查是否全是同点数（对子，2-4张都算对子）
  if (ranks.length === 1 && groups[ranks[0]].length >= 2) {
    return {
      valid: true,
      type: 'pair',
      rank: ranks[0],
      cardCount: groups[ranks[0]].length,  // 2/3/4张
      cards
    };
  }

  // 检查是否是连对（拖拉机）
  if (isConsecutivePairs(groups, currentLevel)) {
    const sortedRanks = sortRanks(ranks);
    return {
      valid: true,
      type: 'consecutivePairs',
      ranks: sortedRanks,
      pairCount: sortedRanks.length,
      cards
    };
  }

  // 甩牌（多张不同点数的牌）
  if (isRamble(cards, groups)) {
    return {
      valid: true,
      type: 'ramble',
      cards,
      groups
    };
  }

  return { valid: false, reason: '无法识别的牌型' };
}

// 判断是否是连对
function isConsecutivePairs(groups, currentLevel) {
  const ranks = Object.keys(groups);

  // 至少2对
  if (ranks.length < 2) return false;

  // 每个点数必须至少有2张（构成对子）
  for (const rank of ranks) {
    if (groups[rank].length < 2) return false;
  }

  // 检查是否连续（排除级牌）
  const sortedRanks = sortRanks(ranks);
  for (let i = 1; i < sortedRanks.length; i++) {
    if (!isConsecutive(sortedRanks[i-1], sortedRanks[i], currentLevel)) {
      return false;
    }
  }

  return true;
}
```

**验收标准：**
- [ ] 单张正确识别
- [ ] 对子正确识别（包括4张同点数）
- [ ] 连对正确识别
- [ ] 甩牌正确识别
- [ ] 级牌不参与连对判断

**依赖：** 无

**风险：** 无

### F-014: 牌型大小比较

| 项目 | 内容 |
|------|------|
| 功能ID | F-014 |
| 优先级 | P0 |
| 描述 | 比较两组牌的大小，判断胜负 |

**比较算法：**

```javascript
function compareCards(play1, play2, trumpSuit, leadSuit, currentLevel) {
  // 1. 检查主牌
  const trump1 = containsTrump(play1, trumpSuit, currentLevel);
  const trump2 = containsTrump(play2, trumpSuit, currentLevel);

  // 有主牌的大
  if (trump1 && !trump2) return 1;
  if (!trump1 && trump2) return -1;

  // 2. 同为主牌或同为副牌
  // 检查是否跟了首出花色
  const followSuit1 = isSameSuit(play1.cards, leadSuit) || trump1;
  const followSuit2 = isSameSuit(play2.cards, leadSuit) || trump2;

  // 跟花色的大
  if (followSuit1 && !followSuit2) return 1;
  if (!followSuit1 && followSuit2) return -1;

  // 3. 都跟了花色，比较点数
  return compareByRank(play1, play2, trumpSuit, currentLevel);
}

// 按点数比较
function compareByRank(play1, play2, trumpSuit, currentLevel) {
  const rankOrder = getRankOrder(trumpSuit, currentLevel);

  // 对子比较
  if (play1.type === 'pair' && play2.type === 'pair') {
    return rankOrder[play1.rank] - rankOrder[play2.rank];
  }

  // 连对比较（比较最大对子）
  if (play1.type === 'consecutivePairs' && play2.type === 'consecutivePairs') {
    const maxRank1 = getMaxRank(play1.ranks, rankOrder);
    const maxRank2 = getMaxRank(play2.ranks, rankOrder);
    return rankOrder[maxRank1] - rankOrder[maxRank2];
  }

  // 单张比较
  return rankOrder[play1.rank] - rankOrder[play2.rank];
}
```

**验收标准：**
- [ ] 主牌正确判断
- [ ] 大小比较正确
- [ ] 连对比较正确

**依赖：** F-013

**风险：** 复杂场景判断

## 6. 数据结构

### 牌型信息 (CardType)
```javascript
{
  valid: boolean,
  type: 'single' | 'pair' | 'consecutivePairs' | 'ramble',
  rank: string,           // 主点数
  ranks: string[],        // 连对的点数列表
  suit: string,           // 花色
  isTrump: boolean,       // 是否包含主牌
  cards: Card[],          // 原始卡牌
  pairCount: number,      // 连对的对数
  cardCount: number       // 该点数的张数（对子可能有2-4张）
}
```

**牌型说明**：
- `single`: 单张
- `pair`: 对子（2-4张同点数）
- `consecutivePairs`: 连对/拖拉机（至少2对连续）
- `ramble`: 甩牌

### 出牌结果 (PlayResult)
```javascript
{
  valid: boolean,
  cardType: CardType,
  reason: string,         // 错误原因
  suggestedCards: Card[][] // 建议可出的牌
}
```

### 主牌信息 (TrumpInfo)
```javascript
{
  trumpSuit: string,      // 主花色
  levelRank: string,      // 级牌点数（如'2'）
  trumpCards: Card[],     // 所有主牌
  rankOrder: Map          // 点数大小顺序
}
```
