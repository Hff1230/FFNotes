## 2. 并行测试配置

### 2.1 单元测试并行矩阵

| 并行组 | 测试模块 | 预估时间 | 进程数 |
|--------|----------|----------|--------|
| Pool-A | UT-001, UT-002, UT-003 | 3-5分钟 | 3 |
| Pool-B | UT-004, UT-005, UT-006 | 3-5分钟 | 3 |
| Pool-C | UT-007, UT-008, UT-009 | 3-5分钟 | 3 |

### 2.2 Jest 并行配置

```javascript
// jest.config.js
module.exports = {
  // 单元测试配置
  projects: [
    {
      displayName: 'unit-tests',
      testMatch: ['**/单元测试/**/*.test.js'],
      maxWorkers: '50%',  // 使用50%的CPU核心
      testTimeout: 10000,
    },
    {
      displayName: 'integration-tests',
      testMatch: ['**/集成测试/**/*.test.js'],
      maxWorkers: 2,  // 集成测试限制并发
      testTimeout: 30000,
    },
    {
      displayName: 'e2e-tests',
      testMatch: ['**/端到端测试/**/*.test.js'],
      maxWorkers: 1,  // E2E测试串行
      testTimeout: 60000,
    },
  ],
};
```

## 5. 执行脚本

```json
// package.json
{
  "scripts": {
    "test:unit": "jest --selectProjects unit-tests",
    "test:unit:parallel": "jest --selectProjects unit-tests --maxWorkers=4",
    "test:integration": "jest --selectProjects integration-tests",
    "test:e2e": "jest --selectProjects e2e-tests",
    "test:all": "npm run test:unit && npm run test:integration && npm run test:e2e",
    "test:coverage": "jest --coverage",
    "test:watch": "jest --watch --onlyChanged",
    "test:ci": "jest --ci --coverage --reporters=default --reporters=jest-junit"
  }
}
```
