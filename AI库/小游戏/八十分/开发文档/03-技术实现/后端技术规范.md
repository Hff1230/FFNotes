## 4. API 规范

### 4.1 Socket 事件

#### 房间事件

| 事件 | 方向 | 参数 | 说明 |
|------|------|------|------|
| room:create | C→S | - | 创建房间 |
| room:join | C→S | { roomId } | 加入房间 |
| room:leave | C→S | - | 离开房间 |
| room:ready | C→S | { isReady } | 准备/取消 |
| room:list | C→S | - | 获取房间列表 |
| room:joined | S→C | { room } | 加入成功 |
| room:playerJoined | S→C | { player } | 玩家加入 |
| room:playerLeft | S→C | { userId } | 玩家离开 |
| room:playerReady | S→C | { userId, isReady } | 准备状态变化 |

#### 游戏事件

| 事件 | 方向 | 参数 | 说明 |
|------|------|------|------|
| game:bid | C→S | { cards } | 叫主 |
| game:play | C→S | { cards } | 出牌 |
| game:start | S→C | { gameState } | 游戏开始 |
| game:deal | S→C | { cards } | 发牌（私有） |
| game:bidAnnounce | S→C | { userId, cards } | 叫主公告 |
| game:playAnnounce | S→C | { userId, cards } | 出牌公告 |
| game:roundEnd | S→C | { winner, scores } | 回合结束 |
| game:end | S→C | { result } | 游戏结束 |

## 5. 数据存储

### 5.1 Redis 结构

```
# 在线用户
online:users -> Set<userId>

# 用户所在房间
user:room:{userId} -> roomId

# 房间信息
room:{roomId} -> JSON

# 房间列表
rooms:list -> List<roomId>

# 用户Session
session:{token} -> JSON
```

### 5.2 MySQL 表结构

#### 用户表 (users)
```sql
CREATE TABLE users (
  id VARCHAR(36) PRIMARY KEY,
  nickname VARCHAR(50) NOT NULL,
  avatar VARCHAR(255),
  phone VARCHAR(20) UNIQUE,
  email VARCHAR(100) UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login_at TIMESTAMP,
  INDEX idx_phone (phone),
  INDEX idx_email (email)
);
```

#### 游戏记录表 (game_records)
```sql
CREATE TABLE game_records (
  id VARCHAR(36) PRIMARY KEY,
  room_id VARCHAR(10) NOT NULL,
  player_ids JSON NOT NULL,
  winner_team INT NOT NULL,
  final_score JSON NOT NULL,
  duration INT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_created_at (created_at)
);
```

#### 用户统计表 (user_stats)
```sql
CREATE TABLE user_stats (
  user_id VARCHAR(36) PRIMARY KEY,
  total_games INT DEFAULT 0,
  wins INT DEFAULT 0,
  current_level VARCHAR(5) DEFAULT '2',
  highest_level VARCHAR(5) DEFAULT '2',
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 6. 安全措施

### 6.1 输入验证

```javascript
// 验证房间号
function validateRoomId(roomId) {
  return /^\d{6}$/.test(roomId);
}

// 验证卡牌
function validateCards(cards) {
  if (!Array.isArray(cards)) return false;
  if (cards.length === 0 || cards.length > 25) return false;
```

### 6.2 防作弊

- 所有游戏逻辑在服务端执行

- 服务端验证操作的合法性
- 记录操作日志用于审计
