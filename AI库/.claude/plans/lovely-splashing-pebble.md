# 八十分游戏H5开发计划

## 背景

基于现有的掼蛋游戏架构，开发八十分（80分）扑克牌游戏的H5局域网版本。参考掼蛋游戏成熟的WebSocket通信和单文件前端架构，针对八十分规则进行定制化开发。

---

## 技术方案

- **后端**: Node.js + ws (WebSocket) - 端口8082
- **前端**: 单文件HTML + CSS + JavaScript
- **参考**: 掼蛋游戏架构

## 开发步骤

### 阶段1: 基础框架 (复制掼蛋并修改)

**关键文件:**
- 参考: `AI库/小游戏/掼蛋/guandan-server.js`
- 参考: `AI库/小游戏/掼蛋/guandan-lan.html`

**任务:**
1. 复制服务器文件，修改端口为8082
2. 复制客户端文件，调整UI标题
3. 修改发牌逻辑：每人25张 + 8张底牌

### 阶段2: 叫主模块

**参考文档:** `开发文档/01-核心模块/游戏逻辑模块.md`

**任务:**
1. 实现叫主状态机 (bidding phase)
2. 叫主优先级: 4张 > 3张 > 2张 > 1张
3. 底牌交接和扣还

### 阶段3: 出牌规则

**参考文档:** `开发文档/01-核心模块/出牌规则模块.md`

**任务:**
1. 主牌判断 (王 + 级牌 + 主花色)
2. 牌型识别: 单张、对子(2-4张)、连对、甩牌
3. 跟牌规则: 有同花色同牌型必须跟
4. 大小比较: 主牌 > 副牌

**重要:** 无三张、无炸弹

### 阶段4: 计分与升级

**参考文档:** `开发文档/01-核心模块/计分与升级模块.md`

**任务:**
1. 得分计算: K=10分, 10=10分, 5=5分 (总分100)
2. 升级判定:
   - ≥120分: 升3级
   - 110-119分: 升2级
   - 80-109分: 升1级
   - <80分: 守方升级
3. 通关条件: 先打到A获胜

### 阶段5: AI玩家

**任务:**
1. 叫主AI: 评估手牌决定是否叫主
2. 出牌AI: 首攻/跟牌/垫牌策略
3. 托管功能

### 阶段6: 测试

**参考文档:** `开发文档/05-测试方案/`

**任务:**
1. 运行单元测试
2. 4人完整游戏测试
3. AI自动对战测试

## WebSocket消息协议

### 客户端 → 服务器
- `createRoom` - 创建房间
- `joinRoom` - 加入房间
- `ready` - 准备
- `bid` - 叫主
- `passBid` - 放弃叫主
- `selectBottom` - 选择底牌
- `play` - 出牌
- `autoPlay` - 托管

### 服务器 → 客户端
- `roomList` - 房间列表
- `gameStart` - 游戏开始
- `dealCard` - 发牌
- `biddingStart` - 叫主阶段
- `bidWinner` - 叫主结果
- `playAnnounce` - 出牌公告
- `roundEnd` - 回合结束
- `gameEnd` - 游戏结束

## 核心规则差异 (vs 掼蛋)

| 项目 | 掼蛋 | 八十分 |
|------|------|--------|
| 发牌 | 27张/人 | 25张/人 + 8底牌 |
| 主牌 | 无 | 有 (王+级牌+主花色) |
| 叫主 | 无 | 竞叫确定 |
| 牌型 | 多种 | 单张/对子/连对/甩牌 |
| 炸弹 | 有 | **无** |
| 三张 | 有 | **无** |
| 跟牌 | 可pass | **必须跟同牌型** |
| 计分 | 按出完顺序 | K/10/5得分 |
| 进贡 | 有 | **无** |
