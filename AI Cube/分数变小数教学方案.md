# 小学"分数变小数"教学方案

> **核心概念：** 理解分数与小数的关系，掌握通过除法将分数形式的单位换算转换为小数。

---

## 一、教学目标

### 1. 知识与技能
- 理解**十分之几 = 一位小数**、**百分之几 = 两位小数**、**千分之几 = 三位小数**
- 掌握通过**除法**（分子÷分母）将分数转换为小数的方法
- 能熟练进行长度、重量等常见单位的分数→小数换算

### 2. 过程与方法
- 通过"分数 → 除法 → 小数"三步转换
- 发现"分母的 0 的个数 = 小数的位数"规律
- 掌握混合单位换算（如 7 厘米 5 毫米 → 米）

### 3. 情感态度与价值观
- 感受数学在购物、测量等生活场景中的实用性
- 培养从具体到抽象的思维能力

## 四、教学过程

### 环节一：情境导入（约 5 分钟）

**展示：** 一把米尺

**教师引导：**
> "同学们，老师手里这把尺子全长 1 米。现在老师把它平均分成 10 份，每一份是多少？用分数怎么表示？用小数又怎么表示？"

**学生回答：** 每一份是 1/10 米 = 0.1 米

**设计意图：** 从学生熟悉的米尺出发，建立分数与小数的直观联系。

---

### 环节二：探究新知（约 15 分钟）

#### 活动 1：基础概念——分数与小数的对应

```
1 分米 = 1/10 米 = 0.1 米    → 一位小数
1 厘米 = 1/100 米 = 0.01 米  → 两位小数
1 毫米 = 1/1000 米 = 0.001 米 → 三位小数
```

**关键发现：**
> **分母的 0 的个数 = 小数的位数**

#### 活动 2：例题 1——长度换算

> **例题 1：** 3 厘米是多少米？

**解题步骤：**
```
1. 写成分数：3 厘米 = 3/100 米
2. 分子÷分母：3 ÷ 100 = 0.03
3. 答案：3 厘米 = 0.03 米
```

**图示辅助：**
```
|---|---|---|---|---|---|---|---|---|---|  ← 1 米 = 100 厘米
0   1   2   3                           100
        ↑
     3 厘米 = 3/100 = 0.03 米
```

#### 活动 3：例题 2——重量换算

> **例题 2：** 250 克是多少千克？

**解题步骤：**
```
1. 写成分数：250 克 = 250/1000 千克
2. 分子÷分母：250 ÷ 1000 = 0.250
3. 化简：0.250 = 0.25
4. 答案：250 克 = 0.25 千克
```

**规律总结：**
- 1/10 = 0.1（一位小数）
- 1/100 = 0.01（两位小数）
- 1/1000 = 0.001（三位小数）

   - 解：8/100 米 = 0.08 米

3. 75 克 = （ ）千克
   - 解：75/1000 千克 = 0.075 千克

#### 提升练习

4. 1 米 25 厘米 = （ ）米
   - 解：1 + 25/100 = 1 + 0.25 = 1.25 米

5. 3 千克 500 克 = （ ）千克
   - 解：3 + 500/1000 = 3 + 0.5 = 3.5 千克

#### 挑战练习

6. 5 角 8 分 = （ ）元
   - 解：5/10 + 8/100 = 0.5 + 0.08 = 0.58 元

## 六、易错点分析

| 易错点 | 原因 | 纠正方法 |
|--------|------|----------|
| 0.03 写成 0.3 | 没注意位数 | 强调"分母100是两位" |
| 250克写成0.250千克（不化简） | 不知道末尾0可省略 | 强调"0.250 = 0.25" |
| 1米25厘米写成1.25米 | 没有把1米和25厘米分开 | 强调"整数+小数" |
| 5角8分写成0.58元 | 混淆角和分的进率 | 用"0.5+0.08"分步计算 |
