**▍ 2. 原语（可直接移植到 AutoX.js）**

```vb
Function 多点比色(array)          ' 全部点都命中 → 1
    For UBound(array)+1
        If 比色(array(i)) = 0 Then result=0 : Exit For
Function 比色(array)              ' dm.CmpColor(x, y, "hex", 0.9)
Function 移动(x,y)                ' MyRnd=Int(5*Rnd+1)；MoveTo ×3；Delay 移延迟(10)
Function 点击(x,y)                ' 移动 → dm.LeftClick → Delay 点延迟(30)
Function 高速点击(x,y)            ' MoveTo ×2 → LeftClick → Delay 80
Function 找图(picName)            ' dm.FindPic(0,0,1296,758,名,"000000",0.9,0,intX,intY)
```
