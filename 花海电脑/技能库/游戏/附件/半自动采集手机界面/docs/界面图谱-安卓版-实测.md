**▍ 已验证的操作事实**

1. **点击注入有效**：`input tap` 与拟人「零距离 swipe」行为一致（同一目标都是 97.47%）
2. **BACK 键 = 弹出退出确认弹窗**（不是关闭上层界面）
3. **进服流程 adb 走不通**：`启动页→进入游戏→选服面板→点角色卡→回启动页→再点进入游戏→又回面板`；
   logcat 无业务日志（release 包）。→ **进服由用户手动完成**
4. 游戏内界面**几乎完全静止**：1.2s 内仅 0.04% 像素变化（99.70% 静止）
   → 采样点几乎不受帧间噪声影响，**容差可以取很小**
5. **HUD 的本底动效 = 0.97%**（1.5s 内 变化>40 的像素占比）—— 这是判定"点击是否生效"的基准线
6. **进服必须手动**：adb 走不通（详见 `docs/已确认界面-登录流程.md`）
