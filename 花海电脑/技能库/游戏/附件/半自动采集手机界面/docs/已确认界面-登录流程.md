**▍ 流程实测结果（重要）**

```
启动页 --[点(785,510)]--> 选服面板 --[点角色卡]--> 启动页 --[再点(785,510)]--> 选服面板/启动页（往返）
```

**并未成功进服**。实测数据：
- `s0→s1`（点进入游戏）：0.00% — 当 s0 已是面板时此点无效
- `s1→s2`（点角色卡）：96.57% — 面板关闭回启动页
- `s2→s3`（再点进入游戏）：96.33% — 又变了一屏；`s3` 与 `s1` 仅差 3.18% → **s3 ≈ 面板**
- `s3→s4`（+15s）：96.32% → **s4 = 启动页**（不是游戏内）

**对照测试**（排除误判的可能原因）：
- `input tap` 与拟人「零距离 swipe」行为**完全一致**（都是 3.18% / 96.57%）→ **点击方式不是原因**
- 坐标经原始分辨率裁剪核对，落在卡片内部 → **坐标不是原因**
- logcat 里只有 `com.netease.l1: addLayerName`（Unity 渲染线程）刷屏，
  **无任何登录/进服/网络错误日志**（release 包关掉了业务日志）
- 游戏进程 pid 正常（11418），渲染持续 60fps，无崩溃

**结论**：adb 注入可能不足以完成**进服**这一环（疑需真人 SDK 交互或存在风控），
或该账号/服务器状态不可进。→ **登录/进服交给用户手动完成，我进游戏内后接管建图。**
