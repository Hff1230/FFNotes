## 五、已知问题 / 待办

- **共享角落点无效**：部分屏的点落在左上标题区/右上✕，这些位置每个屏都一样，对识别没有区分力（靠点数多取胜）。建议每屏补 1~2 个「屏内独有」点。
- **同名/近名重复**：如「主界面HUD」与「主界面」并存，判定时会互相打平，建议合并。
- **未采集**：`小地图`（点小地图后的大图）、`挂机后的画面`，以及 3 个需到现场才能触发的动作（接货运任务 / 继续对话 / 更多操作）。
- 识别层可选的 OCR 关键词通道当前**关闭**（用户要求采集期不 OCR）。
