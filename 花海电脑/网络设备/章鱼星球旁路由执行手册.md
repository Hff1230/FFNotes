**■ 章鱼星球（二手）→ 旁路由 · 执行手册**

> 目标：把一台**二手章鱼星球**（Octopus Planet / Amlogic S912）刷成 OpenWrt，作为**旁路由（旁路网关）**挂在现有主路由下，不动主路由硬件、可逆。
> 默认参数：IP `192.168.1.1` / 用户 `root` / 密码 `password`，WiFi SSID `OpenWrt`（无密码）。

**■ 一、二手机器：先探状态，别急着刷**

二手 = 状态未知：可能已被刷过（安卓/Armbian/OpenWrt 各版本）、可能是**克隆版**、eMMC 可能被写坏过。

**▍ 1.0 通电观察（不动它）**

1. 接 HDMI + 网线到主路由，上电，看开机画面：
   - 进安卓桌面 → 原厂或精简安卓
   - 出现 `login:` / 黑底白字 → Armbian / OpenWrt
   - 黑屏无输出 → 可能 bootloader 坏了
2. 在主路由的**DHCP 客户端列表**里找新设备；或电脑上依次试：

```bash
ping 192.168.1.1      ＃ ophub/flippy 固件常用
ping 192.168.10.1     ＃ 部分 GD 固件
```

3. 若能 SSH 进去，记录现状：

```bash
uname -a
cat /proc/device-tree/model      ＃ 会显示 Octopus Planet 之类
nproc                            ＃ 核数：应为 8（4 核 = dtb 用错/克隆版）
lsblk ; fdisk -l                 ＃ 看 eMMC 容量（8G 或 16G）
```

**▍ 1.1 判定原版 / 克隆版（写 eMMC 前必须确定）**

| 型号 | ophub 安装编号 | 备注 |
|---|---|---|
| 原版 V1.1 | `201` | 用 `u-boot-zyxq.bin` |
| 原版 V1.2 / OneCloud Pro | `213` | |
| **克隆 / 山寨版** | `202` | 需要 `bl-fake-octopus-planet.bin` |

- **实测判据**：按 `201` 刷完若 **只有 4 核 / 网卡不识别 / 起不来** → 大概率克隆版，改刷 `202`。
- 常见配置：2G DDR3 + 8G 或 16G eMMC（看批次）。

**■ 二、工具与文件清单**

**硬件**

- `USB_Burning_Tool`（线刷软件，Amlogic 官方）
- 短接线 / 「景晨刷机神器」（线刷触发工具，或自己短接 eMMC 焊点）
- 一个 **U盘**（≥8G）——⚠️ 想写入 eMMC 就**别用 SD 卡**，用 U 盘（恩山实证）
- USB 键盘 / 显示器接线（HDMI）方便看启动

**镜像**

- `S912安卓精简.img`（线刷底包，重置 bootloader 用）
- `openwrt_s912_k*.img.gz`（ophub/amlogic-s9xxx-openwrt 的 Release）
  - 备选整包：DroidForge 的 **OpenWrt 23.05.4 / Linux 6.1**（自带 LuCI + AdGuard Home + VPN + USB modem auto-dial）
  - 也可用 F大(flippy) 的 op（配改版 bl）
- `Win32DiskImager`（把 img 写入 U 盘）

**■ 三、刷机（二手 → 走"已刷过"简化流程）**

> 原厂从没刷过才需要 CoreELEC→Armbian→op 三重 U 盘启动那套完整流程。
> **二手/已刷过**只需下面 4 步 + 捅菊。

1. **线刷 `S912安卓精简.img`**
   - 打开 USB_Burning_Tool，导入 img，点「开始」
   - 按住短接点（或景晨神器）再插入 USB → 工具识别到设备后才松手
2. **写 U 盘**
   - `Win32DiskImager` 把 `openwrt_s912_k*.img` 写入 U 盘
3. **U 盘启动**
   - 拔掉盒子电源 → 插上 U 盘 → **捅住 Reset（菊花）** → 插上电源 → 看到**章鱼星球 LOGO 后松开**
4. **写入 eMMC**
   - 电脑静态 IP 设 `192.168.1.x`（x≠1），浏览器开 `http://192.168.1.1`
   - 登录 `root` / `password`，**先改密码**
   - 在 op 里执行安装：ophub 固件用「系统 → 晶晨宝盒 → 安装 OpenWrt → 选择 eMMC」或命令行 `install-to-emmc` 脚本；flippy 固件跑 `./install.sh`
   - 安装编号选 `201`（原版）或 `202`（克隆版）

**▍ 3.1 必须避开的坑**

- **写完 eMMC：先拔电源关机 → 再拔 U 盘 → 最后上电。** 直接拔 U 盘会出问题。
- eMMC 设备名可能是 **`/dev/mmcblk1`** 而不是 `mmcblk0`；装错位置会"提示成功但其实写了个空"。
- dtb 必须是 **`meson-gxm-octopus-planet.dtb`**（flippy 固件需手动改 `uEnv.txt` 和 `install.sh`），不改会被认成 N1、**只有 4 核**。
- 某些"4M 刷机底包"刷出的 op 有玄学问题（如微信发不了图）→ 用传统线刷流程。
- **想恢复原厂**：线刷回 `S912安卓精简.img`。

**■ 四、旁路由配置（OpenWrt 后台，sspai 标准 8 步）**

**网络 → 接口 → LAN → 修改**

1. **常规设置**：协议=静态地址，IP 设成与主路由**同网段**且不冲突。
   例：主路由 `192.168.1.1` → 旁路由 `192.168.1.2`
2. **默认网关 = 主路由 IP**（`192.168.1.1`）
3. **高级设置 → 使用自定义 DNS = 主路由 IP**
4. **DHCP 服务器 → 勾选「忽略此接口」**
5. **DHCP 服务器 → IPv6 设置 → 禁用全部 IPv6 服务**
6. **网络 → 防火墙 → 关闭「SYN-flood 防御」**
7. 保存并应用 → **重启一次**
8. **让流量走它**（二选一）：
   - **方式一（只影响指定设备）**：在该设备上手工把「网关」和「首选 DNS」改成 `192.168.1.2`
   - **方式二（全网生效）**：在主路由的 DHCP 服务器里，把**下发的网关和 DNS** 改成 `192.168.1.2`（在主路由上设置！不在旁路由设）

**保底：如果国内网站上不去**（关掉 LAN 桥接、WAN/LAN 共用 eth0 的前提下）

```bash
iptables -t nat -I POSTROUTING -o eth0 -j MASQUERADE
```

> 原理：把非对称路由用二次 NAT 强行改成对称路由。代价是双重 NAT。

**口诀**：没 WAN 口就加一个 —— 关闭 LAN 桥接，新建 WAN 接口绑在 `eth0`，WAN/LAN 共用一根线，WAN 出口自动做 SNAT。

**■ 六、性能预期与风险（不粉饰）**

- **转发性能**：S912（8×A53，4核@1.5G+4核@1.0G）**别指望千兆线速**，实测通常落在**几百兆量级**，开代理/加密后还要打折。**准确数字只能 iperf3 实测。**
- **双重 NAT**：旁路由方案必然引入（MASQUERADE），影响 P2P/BT 的 NAT 类型和少量延迟。
- **单点故障**：旁路由是网关，它挂了 → 全网断（改主路由网关即可恢复）。
- **克隆版风险**：山寨版（202）用错 bootloader 会变砖，刷前务必判定版本。

**■ 七、想升级 / 换固件**

U 盘写新 img → 插 U 盘 → 优先从 U 盘启动（已刷过的机器会自动优先 U 盘启动）→ 重跑写入 eMMC。
