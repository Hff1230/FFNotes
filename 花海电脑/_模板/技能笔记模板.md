# 技能笔记模板（不要直接改这个文件，复制一份用）

复制本文件到 `技能库/<分类>/<中文标题>.md`，然后把下面的正文替换掉。

```markdown
---
title: 中文标题
分类: 游戏            # 只能是：游戏 / 办公文档 / 设计创作 / 自动化运维 / 开发编码 / 研究学习 / 其他
来源技能: hermes-技能名
来源路径: C:\Users\Administrator\AppData\Local\hermes\skills\...
同步时间: YYYY-MM-DD HH:MM
tags: [技能库, 分类名, 关键词]
---

## 技能说明

一句话说清这个技能是干什么的、什么时候用。

## 怎么用

命令 / 步骤。

## 坑

踩过的坑，一条一行。
```

约定（详见 [[00-技能库索引]] 第二节）：

1. 手写笔记要在 `_工具/技能清单.json` 里补一条记录，分类只用固定 7 类。
2. 自动导出的笔记是**只读镜像**，正文由 `_工具/sync_skills.py` 覆盖，别在上面改内容。
3. 文件名用中文标题 + `-` 连接，不带空格。
