## 2. 数据表（DBHelper.ets）

```sql
books(id, title, author, format, path, cover, size, addTime, lastReadTime,
      progress REAL, offset INTEGER, chapterIndex INTEGER, chapterTitle TEXT, encoding TEXT)
bookmarks(id, bookId, offset, chapterIndex, chapterTitle, excerpt, createTime)
settings(skey PRIMARY KEY, svalue)          -- pageMode / fontSize / lineHeight / 主题 / tts* 等
folders(id, name, createTime, sortOrder)
book_sources(id, name, url, groupName, enabled, searchUrl, searchMethod, …)   -- 仅自用版
```

**位置三件套**（阅读进度的权威表示）：`offset`（全书字符偏移，最精确）+ `chapterTitle`（章节名，正文重排后仍可信）+ `progress`（百分比，兜底）。
恢复优先级见 [[03-纯阅关键约定与踩坑]]「位置锚」。

## 3. 两套包（同一份代码）

| product | 用途 | 书源 | 签名 | 产物 |
|---|---|---|---|---|
| `default` | 自用版·带书源 | `ENABLE_BOOK_SOURCE=true` | `default`（调试证书） | `entry/build/default/outputs/default/entry-default-signed.hap` |
| `gallery` | 上架版·无书源 | `false` | `releaseSign`（发布证书，**手工签**） | `build/outputs/gallery/HuaweiReader-gallery-release.app` |

代码里读 `BuildProfile.ENABLE_BOOK_SOURCE` 决定是否渲染书源入口。上架包还需：摘掉 INTERNET 权限 + 确认包里无书源痕迹（`tools/verify-app` / `tools/build_gallery_nosource.py`）。

## 4. 构建命令（照抄）

```bash
cd E:\HuaweiReader
export NODE_HOME="C:/Program Files/Huawei/DevEco Studio/tools/node"
export DEVECO_SDK_HOME="C:/Program Files/Huawei/DevEco Studio/sdk"     # ❗不设会直接 BUILD FAILED
HV="C:/Program Files/Huawei/DevEco Studio/tools/hvigor/bin/hvigorw.js"

# 自用版（hvigor 直接签名，真机可装）
"$NODE_HOME/node.exe" "$HV" assembleHap --mode module  -p product=default -p buildMode=release --no-daemon

# 上架版：先出未签名包，再用发布证书手工签（hvigor 签这一步有问题）
"$NODE_HOME/node.exe" "$HV" assembleApp --mode project -p product=gallery -p buildMode=release --no-daemon
JAVA="C:/Program Files/Huawei/DevEco Studio/jbr/bin/java.exe"
TOOL="C:/Program Files/Huawei/DevEco Studio/sdk/default/openharmony/toolchains/lib/hap-sign-tool.jar"
PW=$(cat signing/store-password.txt)
"$JAVA" -jar "$TOOL" sign-app -mode localSign -keyAlias "releaseKey" -signAlg "SHA256withECDSA" \
  -appCertFile "E:/HuaweiReader/signing/release.cer" -profileFile "E:/HuaweiReader/signing/release.p7b" \
  -inFile "E:/HuaweiReader/build/outputs/gallery/HuaweiReader-gallery-unsigned.app" \
  -keystoreFile "E:/HuaweiReader/signing/release.p12" \
  -outFile "E:/HuaweiReader/build/outputs/gallery/HuaweiReader-gallery-release.app" \
  -keyPwd "$PW" -keystorePwd "$PW"
```

⚠️ `build-profile.json5` 的 **gallery 产品不要填 `signingConfig`**（填了报 `ENOENT: signing\material`）。

## 5. 真机调试姿势（华为 Pura 70 Pro，hdc over WiFi）

```bash
HDC="/c/Program Files/Huawei/DevEco Studio/sdk/default/openharmony/toolchains/hdc.exe"
T=192.168.3.188:5555                     # 真机；127.0.0.1:5555 是模拟器
"$HDC" -t $T install -r 'E:\HuaweiReader\...\entry-default-signed.hap'   # ⚠️ 必须用反斜杠绝对路径
"$HDC" -t $T shell aa start -a EntryAbility -b com.longxia.huaweireader
"$HDC" -t $T shell "hilog -x -T reader"            # 应用日志（进度/装载/翻页都打在这）
"$HDC" -t $T shell "snapshot_display -f /data/local/tmp/x.jpeg"  &&  "$HDC" -t $T file recv /data/local/tmp/x.jpeg '<PC反斜杠路径>'
"$HDC" -t $T shell "hidumper --mem <pid>"          # 内存（PSS / arkts 堆 / native 堆 / swap）
"$HDC" -t $T shell "ls -la /data/app/el2/100/base/com.longxia.huaweireader/haps/entry/files/books/"   # 沙箱里的书与 .idx
```

**装完必须重启 App**（`aa force-stop` 或从最近任务划掉）才用上新代码；只 install 不重启，跑的还是旧进程（踩过：以为修好了，其实点的是旧代码）。
