# 纯阅 · 功能规格

> 规格 = **软件应该是什么样**。改需求先改本文，再改代码。
> 标注：`✅ 已实现并验收` / `⚠️ 已实现但验收未过` / `⬜ 未实现`

## 1. 书架（Index.ets）

| 功能    | 规格                                                                                   | 状态               |
| ----- | ------------------------------------------------------------------------------------ | ---------------- |
| 导入    | 系统文件选择器，只收 `.txt/.epub`；**必须校验复制结果**（网盘/下载未写完的文件会被拒收并提示原因）                           | ✅                |
| 网格    | 封面网格 + 书本信息（标题/大小/进度），空书架显示引导                                                        | ✅                |
| 长按菜单  | 续读 / 从头读 / 移动到文件夹 / 分享 / 备份到文档 / 移出书架（弹层自绘：系统 `promptAction.showDialog` 在鸿蒙 7 真机上不弹） | ✅                |
| 续读    | 点书直接进阅读页，恢复上次位置（口径见 [[03-纯阅关键约定与踩坑]] 的「位置锚」）                                         | ⚠️ 用户实测仍会跳/续读 0% |
| 从头读   | **先把进度清零写进库**再进阅读页（只改内存副本会被退出保存覆盖回去）                                                 | ✅                |
| 文件夹   | 新建/重命名/删除文件夹，书可移入移出；删除书同时清掉沙箱副本                                                      | ✅                |
| 备份到文档 | 长按 → 保存对话框 → **按 fd 分片写入**（不能 `copyFile` 到 uri），失败时清掉 0B 空文件                         | ✅ 已修，待重启后验收      |
| 分享    | 系统分享面板（Share Kit）分享书文件本体 / 书签摘录文本                                                    | ✅                |
| 顶部    | 一行：图标 + 应用名 + 版本号 + 「我的书架」                                                           | ✅                |

## 2. 阅读页（Reader.ets）

### 2.1 两种翻页模式（用户可在设置里切换，记在 `settings.pageMode`）

| 模式                         | 规格                                                               | 状态               |
| -------------------------- | ---------------------------------------------------------------- | ---------------- |
| **左右翻页**（`pageMode=true`）  | 按整页排版，点击/滑动翻页；**必须有真实翻页过程动画——禁止一帧硬切到下一页文字**（逐帧展示位移/投影/页缘，实现见 [[03-纯阅关键约定与踩坑]] 的 `PaperTurnPane`） | ⚠️ 组件已写好，**未接线** |
| **上下滚动**（`pageMode=false`） | **按章切换**：同一时间只渲染当前章，章节之间**不同时出现在屏幕上**；一章滚到底自然停住，不续排下一章 | ⚠️ 与规格不符（现为无缝多章连排），待改造 |
| 章末过渡 | 滚到本章末尾时显示「**下一章**」按钮，**点按才切**（防误触）；切章后位置重置到新章开头 | ⬜ 待实施 |
| 章首过渡 | 停在本章开头时显示「**上一章**」按钮，点按切到上一章并停在**该章末尾**；**首章不显示** | ⬜ 待实施 |
| 底部状态                       | 章名 + 第 N/M 页（或章）+ 进度百分比                                          | ✅                |

### 2.2 阅读设置（面板自绘）

字号、行距、主题（浅色/深色/护眼等）、页边距、翻页模式切换、自动翻页（间隔秒数）、听书（语速/音调/音色）——设置项全部落 `settings` 表，重进生效。

### 2.3 目录 / 书签 / 进度

- 目录：几千章也只用可视区渲染（`ChapterDataSource` 懒加载）
- 书签：当前位置加书签、列表跳转、删除
- 进度条：**只读**（防误触打乱位置），显示 `已读 N%` 无障碍文案
- 跳转来源标记：目录/书签/进度条跳转都算「用户主动」→ 允许写库（别被自检当伪值拦掉）

### 2.4 听书（TTS，BookSpeaker.ets）

播放/暂停、进度（第 N/M 段）、语速 0.7~2.0、音调 0.8~1.5、音色列表；播放时按段落高亮并自动翻页/滚动；切章自动接续。**翻页模式下的听书自动翻页 + 高亮可见性**是最近在补的点。

### 2.5 说明书（GuideBook.ets）

首启/更新后写入沙箱并入库成一本「说明书」，**跟随界面语言**（11 语言），可还原。

**▍ 2.6 位置与进度（规格级要求，2026-10-14 新增）**

> 以下是从「不许损坏阅读进度」红线（见 [[00-纯阅总纲]]）推导出的**规格级要求**：**与实现方式无关**，无论后续用哪套定位方案都必须满足。
> 实现口径与修复计划见 `docs/fix/scroll_progress_jump/fix-plan.md`；测试判据见同目录 `test-strategy.md`。

- **随滚动方向单调**：上下滚动时，章名 / 第 N 页 / 百分比必须随滚动方向单调变化（向下只增不减、向上只减不增）；**允许不变，不允许反向跳，不允许跳章**——不管幅度多小。
- **停手后必须稳定**：滚动停止后位置不得再自行变化（含 8 秒节流落库那一刻）。
- **无交互期不得改位置**：自打开书起、用户没碰过屏幕之前，位置推导不得推进章号。
- **宁可不写，不写伪值**：任何"可能不真实"的位置一律不落库，并留可读的拦截日志（`保存进度被拦：原因`）。
- **间接量不得作为进度来源**：像素、估算高度、比例换算只能用于**落位与校验**；进度的权威值永远是 `offset`（位置三件套口径见 [[03-纯阅关键约定与踩坑]]）。
- **恢复走三态回退**：按 [[03-纯阅关键约定与踩坑]] 的「位置锚」执行，章节名优先于偏移。

## 3. 书源（仅自用版；SourcePage.ets + 书源子系统）

| 功能 | 规格 | 状态 |
|---|---|---|
| 书源管理 | 导入（文件/网址 `legado://import/bookSource` 一键链接）、启用/停用、一键清除失效 | ✅ |
| 检测 | 站点探针：只有「解析不了/超时/5xx」才算死源（4xx 是防盗链，不算）；app 检测关键词固定「小说」 | ✅ |
| 搜索/目录/正文 | 按纯阅自用的规则子集执行（**不支持 `{{ }}` JS、JSONPath、`<js>` 解密**），带每站限速、并发批抓、断点续抓、限流退避重试 | ✅ |
| 抓取入库 | 「开抓即入库、边抓边刷进度」：抓一半的书也留在书架显示「抓取中·N章」 | ✅ |
| 追加更新 | 认书名不认源；换源只补新章；重复段落有专门处理（见 03） | ✅ |
| 上架版 | 书源相关代码/入口整块摘除（`ENABLE_BOOK_SOURCE=false`） | ✅ |

## 4. 关于 / 系统

- 关于页：版本、包名、更新内容（按界面语言）、联系反馈（空值不显示）
- 语言切换：11 种，切换后重启生效
- 无网络权限版本（上架版）：移除 INTERNET 权限

见 [[04-纯阅待办与验收]] 的验收清单——**每一条都要有判据**（看日志/看文件大小/看界面数字），不接受"看起来好了"。
