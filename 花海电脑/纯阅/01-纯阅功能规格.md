## 1. 书架（Index.ets）

| 功能 | 规格 | 状态 |
|---|---|---|
| 导入 | 系统文件选择器，只收 `.txt/.epub`；**必须校验复制结果**（网盘/下载未写完的文件会被拒收并提示原因） | ✅ |
| 网格 | 封面网格 + 书本信息（标题/大小/进度），空书架显示引导 | ✅ |
| 长按菜单 | 续读 / 从头读 / 移动到文件夹 / 分享 / 备份到文档 / 移出书架 / **整理报告**（弹层自绘：系统 `promptAction.showDialog` 在鸿蒙 7 真机上不弹） | ⚠️ 整理报告入口 ⬜ |
| 续读 | 点书直接进阅读页，恢复上次位置（口径见 [[03-纯阅关键约定与踩坑]] A-2「位置锚」） | ⚠️ 用户实测仍会跳/续读 0% |
| 从头读 | **先把进度清零写进库**再进阅读页（只改内存副本会被退出保存覆盖回去） | ✅ |

| 备份到文档 | 长按 → 保存对话框 → **按 fd 分片写入**（不能 `copyFile` 到 uri），失败时清掉 0B 空文件 | ✅ 已修，待重启后验收 |
| 分享 | 系统分享面板（Share Kit）分享书文件本体 / 书签摘录文本 | ✅ |
| **多选与批处理** | 长按进多选：批量移出/移动/分享；50 本书下操作 ≤2s | ⬜ |
| **排序与搜索** | 排序：最近阅读 / 添加时间 / 大小；支持按书名搜索 | ⬜ |

| 顶部（2026-10-15 用户口径改版） | **两行**：① 图标 + 应用名 + 版本号 + 「本地存储 · 无广告无联网」（版本号后面那行小字，随语言自动收窄/省略号，不挤屏）…… **「关于」靠屏幕右边** ② **「我的书架」四个字真正居中**（`Stack` 两层：底层整行居中标题、上层右对齐的按钮行）+ 同一行右端 **「书源 / 导入」**。**不再单独一行显示「N 本」**（用户口径：文件夹「全部 2」已经显示本数）。原因：原来 4 样挤一行、右边再挂按钮，中文就叠字、英文（PureRead / My Bookshelf）更放不下（实测「Import」被屏幕右边缘切掉） | ✅ |

## 2. 阅读页（Reader.ets）

### 2.1 两种翻页模式（设置开关，记在 `settings.pageMode`）

| 模式 | 规格 | 状态 |
|---|---|---|
| **左右翻页**（`pageMode=true`） | 按整页排版，点击/滑动翻页；**必须有真实翻页过程动画——禁止一帧硬切**（见 [[03-纯阅关键约定与踩坑]] D 的 `PaperTurnPane`） | ⚠️ 组件已写好，**未接线** |
| **上下滚动**（`pageMode=false`） | **按章切换**：同一时间只渲染当前章，章节之间**不同时出现在屏幕上**；一章滚到底自然停住，不续排下一章 | ⚠️ 与规格不符（现为无缝多章连排），待改造 |
| 章末过渡 | 滚到本章末尾显示「**下一章**」按钮，**点按才切**；切章后位置重置到新章开头 | ⬜ |
| 章首过渡 | 停在本章开头显示「**上一章**」按钮，点按切到上一章并停在**该章末尾**；**首章不显示** | ⬜ |
| 短章 | 一章不足一屏时不产生"滚到末尾"事件，两个按钮按"章首/章末同时可见"处理（首/末章规则仍适用） | ⬜ |
| 底部状态 | 章名 + 第 N/M 页（或章）+ 进度百分比 | ✅ |

### 2.2 阅读设置（面板自绘）

字号、行距、**段间距**、主题、页边距、翻页模式、自动翻页（间隔秒数）、听书语速/音调——落 `settings` 表，重进生效。
**音色不在这里**：音色**按书记录**（`books.ttsVoice`），解析规则见 §2.4。

### 2.3 目录 / 书签 / 进度

- 目录：几千章也只用可视区渲染（`ChapterDataSource` 懒加载）；**支持卷/部层级折叠**、`（续N）` 折叠、**缺章占位项**（见 §2.7）
- 书签：当前位置加书签、列表跳转、删除
- 进度条：**只读**（防误触打乱位置），显示 `已读 N%` 无障碍文案
- 跳转来源标记：目录/书签/进度条跳转都算「用户主动」→ 允许写库

### 2.4 听书（TTS，BookSpeaker.ets）

播放/暂停、进度（第 N/M 段）、语速 0.7~2.0、音调 0.8~1.5、音色列表；按段高亮并自动翻页/滚动；**切章自动接续（不需要用户点按钮）**；**后台/锁屏连续播放**（长时任务，见 [[04-纯阅待办与验收]] 待办 8）。

**音色按书单独记录（2026-10-15 用户要求）**：

- **每本书记自己的音色**（`books.ttsVoice`，person 号；`-1`/未设 = 没单独设过）。在听书面板里选音色 ⇒ **写回这本书**（同时把 `settings.ttsPerson` 更新成「最近一次选择」，作为没设过的书的默认）。
- **打开书时解析**：`本书 ttsVoice ≥ 0` ⇒ 用本书的；否则用全局默认 `settings.ttsPerson`。
- **语言守卫（硬要求）**：解析完还要跟**本书正文语言**对一下 —— 音色语言与正文语言不一致（英文音色 + 中文正文，或反过来）⇒ **自动换成该语言的默认音色**（中文→13 聆小珊、英文→8 Laura）并提示一次；目标语言音色没装就用现有的并在面板里置灰。**绝不让「英文女声念中文小说」**（用户真机报的原话：英文书里选了英语女生，切到中文小说直接听书还是错的）。中文/英文的判定见 [[03-纯阅关键约定与踩坑]] I.6。
- **语速/音调仍全局**（用户只要求音色按书）。判定逻辑抽在 `utils/VoiceRule.ets`（纯函数，离线门禁直接跑）。

**听书时的屏幕行为（2026-10-14 用户口径，硬要求）**：
- **正文照常显示与滚动**：听书**不得**把正文压成「只显示一句」。左右翻页模式与上下滚动模式下，正文都是满屏正常内容/正常滚动，**只有当前朗读的那一段**加高亮底色。
- **点「开始朗读」后自动收起听书设置面板**（面板霸着下半屏就是「只显示一句」的元凶）。
- **高亮按「播报结束」推进，不按「合成结束」推进**：一句真正念完才换下一句的高亮（否则高亮比声音早一整句）。
- **音频由本应用自行渲染播放（2026-10-15 定案，硬要求）**：`speak` 只**取音频流**（`extraParams.playType=0`），PCM 由本进程 `audio.AudioRenderer`（`STREAM_USAGE_AUDIOBOOK`）播 —— 只有这样系统才看得到「本应用在放音频」，后台/锁屏长时任务的一致性校验才过得去（原来播报在**系统 TTS 进程**名下，系统判「没有有效音频播放」→ 约 2 分钟把长时任务判**暂停**并挂起本应用，用户真机两次实证）。**段推进 = 本段音频真实时长**（字节 ÷ 采样率 × 声道 × 2），高亮跟随用同一时钟。引擎不支持只取流时自动回落旧行为（`playType=1`）。详见 [[03-纯阅关键约定与踩坑]] H.5.1。
- 面板确实开着时（用户手动打开），页模式分页要扣掉面板高度（`blockedH()`），保证高亮段不被面板盖住。
- **一句话跨页要按时翻页**（翻页模式）：若正在朗读的段跨两页，按**该句在两页的字数占比**处理 —— 大半句已在下一页（占比 ≤50%）→ 立即翻过去；大半句还在当前页 → 按占比估时，念到分界点再翻。不许出现「声音已念到下一页、屏幕还停在上一页」。
- **搜索找书的结果按「匹配度」全局排序**（2026-10-14 用户要求）：不是按书源堆叠，而是按"最可能是这本书"排前。打分（越大越相关）：书名归一后**精确** 1000 → **前缀** 900-（多余字数）→ **包含** 800-（多余字数）→ **作者精确** 700 → **作者包含** 600 → **近似书名**（LCS 相似度 ×）320~470 / 200~300 / 垫底。同分时书名短的优先。
  · 归一 = 去书名号/空格/顿号逗号句号等标点 + 转小写（「《枪炮、病菌和钢铁》」≈「枪炮病菌和钢铁」）；
  · 近似书名用**最长公共子序列**而不是无序字符重合 —— 前者能把《枪炮、病菌与钢铁》（和/与一字之差，顺序一致）与《钢铁枪炮与病菌》（字对但乱序）区分开（实测分差 1.7 倍以上）。
- **听书保持「当前的翻页方式」，不自动切换（2026-10-15 用户拍板，改掉 2026-10-14 的「自动切左右翻页」）**：在哪种模式点「开始朗读」就留在哪种模式 —— **上下滚动模式开听书不再切成翻页**。滚动模式靠**居中跟读**兼容听书：每 600ms 按实测语速把「正在朗读的这一句」摆到屏幕正中（章首/章尾由 `[0,maxScroll]` 夹取，长句改为盯住正在读的那一行）。前提已变：听书期间用户手势被锁（`ttsOpLock()`，滚动不许手滑，见 [[03-纯阅关键约定与踩坑]] D2）⇒ 当年「视口滚动 + 长段落块 + 用户手动滚」三件事打架的前提不存在了。
  - **2026-10-16 真机定案与口径（用户实听确认，别再当 bug 修回去）**：
    ① 章末「上一章/下一章 按钮看不到、最后几句看不全」的**真凶是末块插值**：`Reader.ets` 的 `pixelOfLocal` 旧代码末块回退 `y1 = y0 + fontSize*lineHeight` 把上千 px 高的**章内最后一块**当成一行算 ⇒ 章末每句估算 y 低估最多约一个块高（≈400vp）⇒ 跟读目标偏小、视图停在真底之上、页脚掉出视口。已改成该块自身估算高（`blockEstHeight(bi)`）；另把跟读目标上界放宽为 `maxScroll + band`（估算偏小的章才能到真底）。
    ② **章首不插留白（用户拍板 B）**：章首第一句**必然贴顶**（其上没有可滚内容），属**已知设计行为**，不再按「居中异常」处理。
    ③ **章末最后一屏视图钉底读完**，高亮会从屏幕上部往下走；用户 2026-10-16 实听反馈「**句末高亮现在就很好**」⇒ **不要**再开 `contentEndOffset` 尾部留白。
    ④ 定位类判据一律**以真机截图量像素为准**：日志 `dev`/`hrel` 是「估算像素 − 真实像素」混算，实测同刻 `hrel=−641` 而画面上高亮在屏内 48%（差 0.8~0.9×band），不能当绝对判据。
- **按语速预测、边读边跟**（2026-10-14 用户口径："不读完都不换页太笨了；应该根据语速预测下时间主动切"）：听书跟读不看「段读完没读完」，而是用**实测语速**（每段真实耗时平滑出来的 字/秒）推算「此刻大概读到第几个字」，让那个字**始终待在屏幕中间**（滚动模式滚动居中、翻页模式翻页；见 [[03-纯阅关键约定与踩坑]] C.5.3）。起一个 600ms 的跟随定时器，带内迟滞以免每 tick 都抖。
- **后台/息屏听书时，进度必须以「朗读位置」为准**：后台时视口滚不动，`currentOffset()`（由 curY/maxScroll 推）会冻在旧值，照它写库就会出现「后台听了一章，回来还在老位置」。所以听书期间保存的 offset = 章起点 + 当前朗读段偏移；并且**听书播放视为已交互**（G1 例外）→ 允许在有「位置未稳定/伪值」拦截的情况下照常落库。
- **滚动模式必须跟着读**（用户报过「高亮都到下一页了，屏幕没滚」）：判定可见性要看**段尾**，不能只看段首 —— 段可以很长（对话常 60~150 字），段首刚露头、段尾早掉出屏外。整段装不下时先顶段首，念到后半段再把段尾带进视野。

### 2.5 说明书（GuideBook.ets）

首启/更新后写入沙箱并入库成一本「说明书」，**跟随界面语言**（11 语言），可还原。

### 2.6 位置与进度（规格级要求，与实现方式无关）

- **随滚动方向单调**：章名 / 第 N 页 / 百分比随滚动方向单调变化（向下只增不减）；允许不变，**不允许反向跳、不允许跳章**——不管幅度多小。
- **停手后必须稳定**：滚动停止后位置不得再自行变化（含 8 秒节流落库那一刻）。
- **无交互期不得改位置**：自打开书起、用户没碰过屏幕之前，位置推导不得推进章号（**听书播放视为"已交互"**，见 03-A-4）。
- **宁可不写，不写伪值**：任何"可能不真实"的位置一律不落库，并留可读拦截日志。
- **间接量不得作为进度来源**：像素/估算高度/比例换算只用于落位与校验；进度权威值永远是 `offset`。
- **恢复走三态回退**（见 03-A-2）。

### 2.7 文本整理（规格级，2026-10-14 定案）

> 实现细节见 [[docs/design/2026-10-14-文本整理流水线|文本整理流水线]]；本文只写"应该是什么样"。

| 项 | 规格 | 状态 |
|---|---|---|
| **本地书** | **原文一个字节都不许改**；整理只影响"怎么显示"（视图文本 + 显示层），可一键切回「按原始文本显示」 | ⬜ |
| **抓取书** | **抓取时先整理提纯再落盘**（磁盘上的就是干净文本）；**原始正文留档**，可「另存未整理版」或整本重跑 | ⬜ |
| **口径** | **白名单提纯**：除「正文、章节名、作者/书名等主要内容」以外**全部清除**——无关空格、网址、广告、水印、来源标注、页码、分隔线一律清掉 | ⬜ |
| 标题 | 清掉站点尾巴（`（1/2）`、`_全本`、`[VIP]` 等），保留章名主体；汉字/阿拉伯数字章号都解析（不改显示文字） | ⬜ |
| 目录结构 | `第X卷/部/篇/集` 作为分组（可折叠）；`（续N）` 折叠；书首"目录块"不当作正文 | ⬜ |
| 缺章 | 章号跳号 → 目录显示「**第N章（缺）**」占位，可一键去书源补章（**不再静默跳过**） | ⬜ |
| 整理报告 | 每本书必须有：扫描/保留行数、各类删除数、**被删行样本**、存疑保留行、缺章列表、规则版本、耗时；书详情页可查看 | ⬜ |
| 安全 | 只删整行（行内只做空格归一）；不确定的行**保留**并进报告；幂等可重跑 | ⬜ |

### 2.8 阅读排版（规格级）

- **段首缩进 2 字符**（默认开，可关）；段间距可调；行距/字号可调。
- 空行策略：段落之间 1 个空行；可选"不显示空行"。
- 主题：纸张 / 米黄 / 护眼 / **夜间（纯黑，OLED 省电）**；**随系统深浅色自动切换**（默认开，可关）。

## 3. 书源（仅自用版；SourcePage.ets + 书源子系统）

| 功能 | 规格 | 状态 |
|---|---|---|
| 书源管理 | 导入（文件/网址 `legado://import/bookSource` 一键链接）、启用/停用、一键清除失效 | ✅ |
| 检测 | 站点探针：只有「解析不了/超时/5xx」才算死源（4xx 是防盗链，不算）；app 检测关键词固定「小说」 | ✅ |
| 搜索/目录/正文 | 按纯阅自用的规则子集执行（**不支持 `{{ }}` JS、`@js:` 真逻辑、`<js>` 解密**；**支持 JSON 接口源**：响应是 JSON 时走 JSONPath 子集求值，搜索/目录/正文三条链路都接 —— 口径见 [[03-纯阅关键约定与踩坑]] §G.1），带每站限速、并发批抓、断点续抓、限流退避重试 | ✅ |
| 抓取入库 | 「**探到内容才入库**」：先探（目录 ≥1 章 + 首章正文 ≥20 字），**探通了才建书架条目**，之后边抓边刷进度（抓一半的书仍留在书架显示「抓取中·N章」）；探不通 ⇒ 不建条目、不留 0B 残留。口径见 [[03-纯阅关键约定与踩坑]] §G.5 | ✅ |
| 抓取失败不残留 | 同名（+作者）**只允许一行**：已有行（哪怕文件不存在/0 字节）复用并改写 path，不再 insert；启动时自清「`dlState=1` + `size=0` + 文件不存在」的死条目（用户报：连续点几个抓不动的源 → 书架多本同名 0B 书） | ✅ |
| 抓取省电 | 非充电 / 移动网络时降并发（单并发 + 每 N 章让出 200ms）；可暂停/续抓 | ⬜ |
| 追加更新 | 认书名不认源；换源只补新章；重复段落有专门处理 | ✅ |
| 上架版 | 书源相关代码/入口整块摘除（`ENABLE_BOOK_SOURCE=false`） | ✅ |

## 4. 关于 / 系统

- **关于页（2026-10-15 用户口径：移到书架首页 + 全屏）**：入口＝**书架首页第一行最右端的「关于」**（自用版与上架版都显示）；**整页全屏**（顶栏「关于 / 收起」固定，正文整页上下滚动 —— 「内容一屏幕放不下就能上下滚动」）；内容＝应用图标/名称 + 版本（读安装包，不写死）+ **开发者 / 版本 / 包名 / 联系反馈** + **本版本更新内容**（按界面语言读随包 `rawfile/changelog_<lang>.txt`，匹配不上回落英文）。阅读设置面板里**不再**放入口（原来只在无书源的上架版显示 → 用户找不到）。
- **「本版本更新内容」随版本同步**（硬要求）：发版前必须把该版本的更新内容写进 **10 份** `changelog_*.txt`（zh / zh_Hant / en / ja / ko / fr / de / es / ru / pt），标题行写版本号；关于页显示的就是这一份。
- **界面语言与回落（2026-10-15 用户口径定稿）**：`resources/<lang>` 共 **10 套**完整文案（zh_CN / zh_Hant / `en` / ja / ko / fr / de / es / ru / pt），每套与 zh_CN **键集合一一对应（168 条）**；**未匹配的语言一律回落 `base`，而 `base` = 完整中文（168 条，与 zh_CN 同内容）** —— 用户口径「未匹配到语言的改为默认中文」（改前 `base` 只有 5 条 ⇒ 未匹配语言界面几乎空白；`en` 目录也是 2026-10-15 才建的，改前选 English 界面文案仍回落中文）。App 名同理：`AppScope/base` = **纯阅**（未匹配语言用中文名），另为 8 个已支持的非中文语言各建 `AppScope/<lang>/element/string.json` = **PureRead**（保持它们原有的英文名）。发版前新增文案必须 10 套 + `base` 同步改（`rawfile/changelog_*.txt` 同理）。
- 语言切换：跟随系统 / 简体中文 / 繁體中文 / English（切换后重启生效）
- 无网络权限版本（上架版）：移除 INTERNET 权限
- **无障碍（规格级）**：所有图标按钮、进度条（"已读 N%"）、翻页/切章按钮必须有无障碍文案；主要路径无"未命名按钮" ⬜
