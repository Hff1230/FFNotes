# 纯阅 · 文本整理流水线（定案）

## 零、定案（2026-10-14，用户拍板）

| # | 决策项 | **定案** |
|---|---|---|
| 1 | 整理结果放哪 | **① 本地书：只做 sidecar / 显示层，原文不动**（不生成整理副本、不覆盖沙箱正文）<br>**② 抓取书：抓取时「整理排版后」再落盘**（存到本地的就是整理好的干净文本） |
| 2 | 默认强度 | **激进**（标题规范化 + 卷章层级 + 缺章占位 + 段落归一 + 去分隔线 + 显示层全开） |
| 3 | 整理报告 | **要**（每本书一份，含删除/修改/缺失明细，可追溯、可还原） |
| 4 | **清理口径（本轮追加）** | **白名单提纯**：**除「正文、章节名、作者/书名等主要内容」以外全部清除后再落盘** —— 无关空格、网址、广告、水印、来源标注、页码、分隔线一律清掉。**不再靠"垃圾行黑名单穷举"**（永远列不完），改为「强特征剔除 + 白名单保留」两段判定（见 §三） |

> **核心不变式（不可违反）**：**本地书原文一个字节都不许改**（有可验证判据，见 §七）。
> **抓取书的含义**：落盘 = 提纯后的视图文本 ⇒ 磁盘上那份就是视图，`offset` 天然稳定；但**原始抓取正文必须留 sidecar**（可审计、可还原，见 §二）。

## 一、现状（代码事实，别重复造）

| 层 | 已有什么 | 缺口 |
|---|---|---|
| 解码 | 编码嗅探（gbk/gb2312/gb18030 → gb18030）、**流式解码**（跨片半汉字）、去 UTF-16 的 0 填充、2MB 分片装载 | 少见编码；BOM 处理 |
| 行级清洗 | `TextUtil.normalize()`：**只做三件事** —— 去控制字符、`\r\n`/`\r` → `\n`、全角空格 → 半角 | ① **本地 txt 没走垃圾行表**（只有抓取侧走）；② 无行内多空格压缩、无行尾空白清理；③ 无连续空行压缩；④ 无"TXT下载/手打版/校对版"等本地常见行 |
| 章节识别 | `CHAPTER_LINE_RE`：第X章/节/回/卷/部/篇/集、Chapter/Chapitre/Kapitel/Capítulo/Глава/제N장/序章/前言/后记/番外；三轮匹配；首章前内容并入第一章 | ① **卷/部与章同级**（目录无层级）；② 标题尾巴（`（1/2）`、`_全本`、`最新章节`）未清；③ **缺章静默跳过**；④ `（续 N）` 目录不折叠；⑤ 书首"目录块"被当正文渲染 |
| 抓取侧 | `cleanChapterBody()` + 垃圾行表（实测拦过 `最新网址：www.xbotaodz.info`、`play("code-2");`）；`normalizeToc()` | 只有黑名单，**没有提纯**；HTML 实体/`<br>` 未还原；原始正文未留档 |
| 段落/排版 | 渲染层（`fontSize=18`、`lineHeight=1.7`、4 主题） | 无段首缩进、无段间距、无空行策略 |

## 二、双路径设计（定案）

```
路径 A｜本地导入（用户提供的 txt/epub）
  原文文件（沙箱副本） ──永不改写──▶ SHA256 不变（硬判据）
        └─ 规则(ruleset vX) ─▶ 视图文本（sidecar / 内存窗口）─▶ 目录 / 渲染 / 位置锚 / 听书
                              └─ 整理报告（删了什么、改了什么、缺了哪章）

路径 B｜书源抓取
  HTML ─▶ 提取正文 ─▶ 原始正文留档（<书>.raw，可审计/可还原）
                     └▶ 【整理提纯：S1 + S2 + S3 + S4】 ─▶ 写入书文件（磁盘 = 视图文本）
                                                       └─ 整理报告（含被删行样本）
```

- **同规则、同版本**：两条路径共用同一套规则与 `rulesetVersion`。
- **抓取追加补章**：`ShelfAutoUpdater` 续抓时用**同一规则**提纯后追加。
- **原始正文留档（抓取路径）**：落盘前把**未整理的原始正文**写进 `<书>.raw` sidecar（按章存、可压缩）——这是"落盘即整理"唯一的安全垫：报告可逐行核对，也能"另存未整理版"或整本重跑。

## 三、清理口径：白名单提纯（定案强度：激进）

> **原则**：**先剔强特征噪音 → 再按白名单保留 → 不确定的按"疑似正文"保留并进报告**（正文丢失不可挽回；噪点留着只是难看）。
> 每行都按下表顺序判定，**判定结果的行数与样本全部进报告**。

**S1 字符与空格归一（所有行先过一遍）**
1. 控制字符、零宽字符（`\u200b-\u200f`、`\ufeff`）→ 删；`\r\n`/`\r` → `\n`；
2. 全角空格 → 半角；**行内连续空格 → 1 个**；行首/行尾空白 → 删；
3. 空行策略：**段落之间保留 1 个空行**（段界）；章首/章末空行 → 删；**连续空行 → 1**。

**S2 强特征剔除（命中即删，不看白名单）**

| 类别 | 判据（示意） |
|---|---|
| 网址/域名 | 含 `http`、`www.`、`://` 或 `.com/.net/.cn/.org/.info/.xyz/.top` 等 |
| 联系方式 | `QQ`、`群号`、`微信`、`公众号`、`扫码`、邮箱、`@` 后接域名 |
| 站点/来源噪声 | `请记住本站 / 最新网址 / 本站域名 / 手机用户请浏览 / 电脑访问 / 首发 / 转载 / 手打版 / 校对版 / TXT下载 / 全集下载 / 本书由…整理` |
| 互动话术 | `求收藏 / 求推荐 / 求月票 / 打赏 / 订阅 / 加更 / 章节报错 / 本章未完 / 下一页` |
| 元数据噪声 | 章节字数统计、更新时间戳、`(本章完)`、各类进度标注 |
| 分隔线/装饰 | 纯 `-`、`=`、`*`、`—`、`·`、`☆`、`★` 重复 ≥3，或纯符号行 |
| 页码/编号 | **纯数字行且位数 ≤3**（疑似页码）；≥4 位纯数字 → 保留（可能是正文数字） |
| 极短噪声行 | 长度 <6 且**不含任何标点**的行（归一后再判） |
| HTML 残留 | 抓取路径先还原 `&nbsp;`/`&#12290;`/`<br>`/`<p>` 再判定；还原后仍剩标签 → 删标签 |

**S3 白名单保留（命中即保留，优先于"存疑"判定）**
1. **章节标题行**：`CHAPTER_LINE_RE` **整行匹配**（第X章/卷/部/篇/集、Chapter/Chapitre/…、序章/前言/后记/番外）；
2. **书元信息行**：`《书名》`、`作者[:：]`、`著`、`内容简介/简介/标签` 及其后紧跟的简介段落；
3. **正文行**：含中文句末标点（`。！？…`）或引号/顿号/分号/冒号，且长度 ≥8；
4. **短句正文行**：长度 <8 **但含句末标点或引号**（对话体，如「"你好。"」）；
5. **外文正文行**：含拉丁字母/西里尔字母且长度 ≥20（避免把英文正文当噪音）；
6. **存疑行**（以上都不命中且未被强特征剔除）→ **保留**，并计入报告「存疑保留 N 行」（供人工复核）。

**S4 结构规范化**
7. **标题规范化**：清标题尾巴（`（1/2）`、`_全本`、`最新章节`、`[VIP]`），保留章名主体；
8. **编号统一解析**：汉字/阿拉伯数字都解析出章号（用于排序与缺章检测，**不回写显示文字**）；
9. **卷/章层级**：`第X卷/部/篇/集` 作为分组节点，其下挂章（目录可折叠）；
10. **缺章占位**：跳号 → 目录插「**第N章（缺）**」，可点击"去书源补章"（联动 `ShelfAutoUpdater`）；
11. **书首"目录块"**：开篇连续 ≥5 行的标题式行且无正文 → 摘出正文，只作为目录（不进正文渲染）；
12. **续章折叠**：`（续1）（续2）…` 在目录里折叠到同章下；
13. **段落归一**：正文里的硬换行（一行一断的杂志式排版）→ 合并成自然段。判据**保守**：行尾无句末标点**且**下一行不以缩进/数字/引号开头才合并。

**S5 显示层**（不改文本，默认全开）
14. 段首缩进 **2 字符**、段间距可调、行距/字号可调；可选"不显示空行"。

**明确不做（写进口径，免得以后反复）**
✖ 繁简转换　✖ OCR 错字纠正　✖ 正文改写/摘要　✖ 章号重编号写回正文　✖ 合并章节

**七条安全阀（激进档必须全有）**
① **只删整行**，行内一律只做空格/实体归一（不删内容）；② **白名单优先**：命中"标题/元信息/正文/短句/外文"一律保留；③ **不确定 → 保留**（宁留不删）+ 报告标记；④ **原始正文留档**（抓取路径 `<书>.raw`）；⑤ **幂等**（同文本两次结果一致）；⑥ **可还原**（本地书一键按原文显示；抓取书按 `.raw` 另存或重跑）；⑦ **报告可逐行审计**（每类留样本）。

## 四、位置锚与"整理"的交叉口径（红线）

1. **`offset` 定义在"视图文本"上**（本地书 = 原文 + 规则；抓取书 = 磁盘文本，两者同一）。
2. **本地书规则升级** → 按「**章节名 + 百分比**」重定位（沿用三态回退），**不许因整理丢进度**。
3. **抓取书规则升级**：**不重写旧章**（免得前后不一致 + 进度漂移），只对新抓章节用新规则；报告标注「跨规则版本：v1（1~800章）/ v2（801~）」。要全书重跑 → **另存为新书**（用 `.raw` 重跑，不动原书进度）。
4. **`.idx` 校验**（字节数 + 字符数）按**整理后**口径计算；本地书规则变化时使 `.idx` 失效并重建。

## 七、验收判据（可量化，不留"看起来好了"）

> ⚠️ **判据唯一来源 = [[04-纯阅待办与验收]]**（见 [[05-纯阅文档地图与维护规则]] §二）。
> 下表是本文的**细化观测方式**，与 04 冲突时**以 04 为准**；04 已收录的条款：原文未改（SHA256）、正文零丢失、噪点清零、空行、目录准确率、缺章、乱码、进度不丢、报告一致性、性能、可回溯。

| 项 | 判据 |
|---|---|
| **原文未改（硬判据）** | 本地书整理前后 **SHA256 完全一致**；沙箱正文大小与 mtime 不变 |
| **正文零丢失（硬判据）** | 抽 20 章逐行比对：**原文中"含句末标点的行"100% 出现在整理后文本中**（允许位置变化，不许缺失） |
| 噪点清零 | 抽 20 章（本地 + 抓取各一份）：网址 / 联系方式 / 广告话术 / 分隔线 / 页码 **残留 0**；**行内多空格、行尾空白残留 0** |
| 空行 | 段落之间恰好 1 空行；无连续空行；章首章末无空行 |
| 目录准确率 | 抽检 50 章（跨卷/续章/带前缀）≥98% |
| 缺章 | 跳号书（800→802）出现「第801章（缺）」且可跳补章 |
| 乱码 | 10 本不同编码的书乱码 **0** |
| 进度不丢 | 整理前后同章同名；重进落点误差 ≤1 屏（走 [[04-纯阅待办与验收]] 阅读进度验收） |
| 报告一致性 | 报告数字与实际 diff 完全对得上；连跑两次**完全一致**（幂等） |
| 性能 | 21.9MB 书后台提纯 ≤1s，不阻塞首屏（首屏 ≤1.5s，见优化方案 P1-4） |
| 可回溯 | 抓取书能「另存未整理版」（与 `.raw` 逐字节一致） |

## 八、风险与反例（激进档重点）

1. **误删正文**（最大风险）：对策 = 白名单优先 + 不确定则保留 + `.raw` 留档 + 报告样本 + 硬判据"正文零丢失"。
2. **提纯过度误伤**：诗行/歌词（无句末标点、短）、表格、英文正文、正文里的数字行 → 已在白名单留"短句/外文/≥4位数字"三类例外；仍误伤 → 报告可查、可加规则重跑。
3. **误合并段落**：对话体、歌词被并段 → 合并判据保守 + 开关。
4. **抓取落盘不可逆** → 已用 `.raw` 兜住（可另存未整理版 / 重跑）。
5. **同书两套规则风格** → §四-3（不重写旧章 + 报告标注）。
6. **性能**：百万行遍历必须分片 + 后台；正则**行首锚定**，禁 `.*` 贪婪扫全文（回溯会炸）；强特征用**多模式一次扫描**，不要每类跑一遍全文。

## 九、待定（不阻塞开工）

- `rulesetVersion` 存哪：DB `settings` 按书一行 vs sidecar 头部（倾向 **sidecar**）；
- 报告保留策略：每书一份覆盖 vs 带历史（倾向**最近一次 + 计数**）；
- `.raw` 占空间（抓取书近似翻倍）→ 是否默认开（倾向**默认开**，允许在设置里关）；
- 「按原始文本显示」开关放设置页还是书详情页（倾向**书详情页**，与报告同处）。
