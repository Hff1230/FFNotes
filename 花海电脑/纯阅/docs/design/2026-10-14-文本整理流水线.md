# 纯阅 · 文本整理流水线（定案）

## 零、定案（2026-10-14，用户拍板）

| # | 决策项 | **定案** |
|---|---|---|
| 1 | 整理结果放哪 | **① 本地书：只做 sidecar / 显示层，原文不动**（不生成整理副本、不覆盖沙箱正文）<br>**② 抓取书：抓取时「整理排版后」再落盘**（存到本地的就是整理好的干净文本） |
| 2 | 默认强度 | **激进**（安全项 + 标题规范化 + 卷章层级 + 缺章占位 + 段落归一 + 去分隔线 + 显示层全开） |
| 3 | 整理报告 | **要**（每本书一份，含删除/修改/缺失明细，可追溯、可还原） |

> **核心不变式（不可违反）**：**本地书原文一个字节都不许改**（有可验证判据，见 §七）。
> **抓取书的含义**：落盘 = 整理后的视图文本 ⇒ **抓取书没有"原文/视图"两套**，磁盘上那份就是视图，`offset` 天然稳定。

## 一、现状（代码事实，别重复造）

| 层 | 已有什么 | 缺口 |
|---|---|---|
| 解码 | 编码嗅探（gbk/gb2312/gb18030 → gb18030）、**流式解码**（跨片半汉字）、去 UTF-16 的 0 填充、2MB 分片装载 | 少见编码；BOM 处理 |
| 行级清洗 | `TextUtil.normalize()`：**只做三件事** —— 去控制字符、`\r\n`/`\r` → `\n`、全角空格 `\u3000` → 半角 | ① **本地 txt 没走垃圾行表**（只有抓取侧走）；② 无行尾空白清理；③ 无连续空行压缩；④ 无"TXT下载/手打版/校对版/手机电子书"这类本地常见行 |

## 二、双路径设计（定案）

```
路径 A｜本地导入（用户提供的 txt/epub）
  原文文件（沙箱副本） ──永不改写──▶ SHA256 不变（硬验收判据）
        └─ 整理规则(ruleset vX) ─▶ 视图文本（sidecar / 内存窗口）─▶ 目录 / 渲染 / 位置锚 / 听书
                                   └─ 整理报告（删了什么、改了什么、缺了哪章）

路径 B｜书源抓取
  HTML ─▶ 提取正文 ─▶ 【整理排版：S2 + S3 + S4 全规则】 ─▶ 写入本地书文件（磁盘 = 视图文本）
                                                     └─ 整理报告
```

- **同规则、同版本**：两条路径共用同一套规则与 `rulesetVersion`，避免"抓来的干净、本地导入的脏"两套口径。
- **抓取追加补章**：`ShelfAutoUpdater` 续抓时用**同一规则**整理后追加，保证同书前后风格一致。

## 三、"激进"档规则清单（定案强度）

**S1 解码层**（已有）：编码嗅探、流式解码、去 0 填充、分片装载。

**S2 行级清洗**（只删"整行命中"，绝不碰行内）
1. 控制字符、零宽字符（`\u200b-\u200f`、`\ufeff`）→ 删；`\r\n`/`\r` → `\n`；全角空格 → 半角；行尾空白 → 删。
2. 连续 ≥2 空行 → **1 空行**（激进档）。
3. 垃圾行表**本地/抓取共用**：`最新网址 / 本站域名 / 请记住本站 / 公告 / 广告 / 扫码关注 / 更多精彩小说 / 手机用户请浏览 / TXT下载 / 手打版 / 校对版 / 全集下载 / 本书由.*整理 / 电子书制作`。
4. **分隔线行**（纯 `-`、`=`、`*`、`—`、`·` 重复 ≥3）→ 删（激进档新增）。
5. HTML 残留（`&nbsp;`、`&#12290;`、`<br>`、`<p>`）→ 抓取路径先还原为真实字符/换行，再进 S2。

**S3 结构规范化**
6. **标题规范化**：清掉标题尾巴（`（1/2）`、`_全本`、`最新章节`、`最新章节请记住`、`[VIP]`），保留章名主体（**只去尾巴，不重写正文标题**）。
7. **编号统一解析**：汉字/阿拉伯数字都解析出章号（用于排序与缺章检测，**不回写显示文字**）。
8. **卷/章层级**：`第X卷/部/篇/集` 作为**分组节点**，其下挂章；目录可折叠（配目录 UI）。
9. **缺章占位**：章号跳号（如 800 → 802）→ 目录插「**第801章（缺）**」占位，可点击"去书源补章"（联动 `ShelfAutoUpdater`）；**不再静默跳过**。
10. **续章折叠**：`（续1）（续2）…` 在目录里折叠到同一章下（正文仍分段渲染，避免单屏几十万字）。
11. **段落归一**（激进档）：段落之间统一为 1 空行；正文里的硬换行（一行一断的杂志式排版）→ 合并成自然段。合并判据**保守**：行尾无句末标点且下一行不以缩进/数字/引号开头才合并。

**S4 显示层**（不改文本，默认全开）
12. 段首缩进 **2 字符**、段间距可调、行距/字号可调；可选"不显示空行"。

**明确不做（写进口径，免得以后反复）**
✖ 繁简转换　✖ OCR 错字纠正　✖ 正文改写/摘要　✖ 章号重编号写回正文　✖ 合并章节

**六条安全阀（激进档必须全有）**
① **只删整行**（行内出现关键词不误伤）；② **正文白名单**：标题识别只认"整行且模式命中"（沿用现有约束），正文里出现"第3章"不当作标题；③ **幂等**：同文本跑两次结果完全一致；④ **可还原**：本地书一键「按原始文本显示」（直接关规则）；⑤ **报告**：每一步都有计数；⑥ **可重跑**：规则升级后按 `rulesetVersion` 重跑（本地书因原文未动，重跑即时生效）。

## 四、位置锚与"整理"的交叉口径（红线）

1. **`offset` 定义在"视图文本"上**（本地书 = 原文 + 规则；抓取书 = 磁盘文本，两者同一）。
2. **本地书规则升级**（文本可能变化）→ 必须按「**章节名 + 百分比**」重定位（沿用三态回退），**不许因整理丢进度**。
3. **抓取书规则升级**：磁盘上的旧章已是旧规则文本 → **不重写旧章**（会造成前后不一致与进度漂移）；仅对新抓章节用新规则，并在报告里标注「本书跨规则版本：v1（1~800章）/ v2（801~）」。用户若要"全书重跑" → 提供**另存为新书**（不动原书进度）。
4. **`.idx` 校验**（字节数 + 字符数）在**整理后**口径上计算；本地书规则变化时使 `.idx` 失效并重建。

## 七、验收判据（可量化，不留"看起来好了"）

| 项 | 判据 |
|---|---|

| 目录准确率 | 抽检 50 章（跨卷/跨续章/含前缀章名）≥98% |

| 乱码 | 10 本不同编码的书乱码 **0** |
| 进度不丢 | 整理前后同章同名；重进落点误差 ≤1 屏（走 [[04-纯阅待办与验收]] 阅读进度验收） |
| 报告一致性 | 报告数字与实际 diff 完全对得上；连跑两次**完全一致**（幂等） |
| 性能 | 21.9MB 书后台整理 ≤1s，不阻塞首屏（首屏 ≤1.5s，见优化方案 P1-4） |
| 抓取落盘 | 抓 100 章后磁盘文本：无 HTML 残留、无站点水印、段落规整，抽查 20 章合格 |

## 八、风险与反例（激进档重点）

1. **误删正文**：正文行恰好等于垃圾行模式（少见但可能）→ 安全阀 ①③⑤ + 报告可查 + 可还原。
2. **误合并段落**：对话体、歌词、诗歌被并成一段 → 合并判据保守（行尾无句末标点才合并）+ 提供开关。
3. **抓取落盘不可逆**：磁盘已是整理文本 → 回退方式是"重新抓一遍该书"（成本低），或另存为新书对比。
4. **同书两套规则风格** → §四-3 已定口径（不重写旧章 + 报告标注跨版本）。
5. **性能**：激进规则要遍历百万行 → 必须分片 + 后台；单行正则**行首锚定**，禁用 `.*` 贪婪扫全文（回溯会炸）。
