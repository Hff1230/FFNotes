**■ 纯阅 · FIX-000 取证可执行单**

> **一句话目的**：用**只加日志、不改逻辑**的方式，确认「上下滚动进度异常跳动」到底是哪条路径引起的（RC-1~4），并**同时留下「按章切换改造之前」的基线日志**。
> **为什么必须现在做**：按章切换（FIX-005）一改，「跨章跳动」现象就变形、基线作废。
> **纪律**：本单**只加日志**。不许顺手改逻辑、不许顺手接 `PaperTurnPane`、不许顺手改按章切换。

**■ 二、插探针日志（E-2：RC-1 的直接判据）**

在**「像素 ↔ 内容位置」换算那一处**（也就是落位自校准 / 滚动推导里算比例的地方）打一行，字段固定为这 8 个。**只打日志，不要改计算。**

| 字段 | 为什么必须要 |
|---|---|
| 估算内容高 | 分母（自校准比例的分母） |
| 真实内容高 | 分子 |
| 比例 | 两者之比 —— **这一项在滚动中是否持续变化，就是 RC-1 的判定** |
| 推出的 `offset` | 即将被写进状态的内容位置 |
| 推出的 `curIndex` | 由它推出的章号 |
| `userScrolled` | RC-3 的判据 |
| `placing` | 落位是否还在收敛 |
| 当前可见首项 index（若已能拿到） | 对照"像素推出来的位置"与"实际可见项"是否一致 |

建议日志前缀统一（便于过滤），例如：`PROBE px2pos est=... real=... ratio=... off=... idx=... user=... placing=... first=...`

**怎么找到插入点（源码不在本机，所以给线索不给行号）**：先在 `Reader.ets` 里 grep 这些词 —— `maxScroll`、`place attempt`、`place done`、`Math.round`、`估算`、`比例`、`scrollTo`、`scrollToIndex`、`currentOffset`。换算处就是"**用估算内容高把像素换回内容位置**"的那几行。

> 若一时定位不到，**退而求其次也有效**：直接在**落位收敛循环**里打这同样的 8 个字段（收敛循环每一轮都会算到这些量），同样能看出 `ratio` 是否在滚动中持续变化 —— 那正是 RC-1 的判据。

**■ 三、复现（一次录屏 + 一次抓日志即可）**

1. 打开那本书 → 进上下滚动模式
2. 从第 1 章往下连续滚 **5~10 屏**，**跨至少 1 个章边界**
3. 滚动过程中盯底部状态栏（章名 / 第 N 页 / 百分比）—— 出现跳动时**记住大概时间点**
4. **停手等 ≥10 秒**（必须跨过 8 秒节流落库那一刻）
5. 直接回桌面（**不要划掉进程**）→ 等 2 秒 → 重开 App → 进同一本书，看落点
6. 再补一次：**从头读 → 立刻退出 → 重开**（看是否被旧进度覆盖）

**■ 四、抓日志（整段，不要只截跳动那两行）**

```bash
"$HDC" -t $T shell "hilog -x -T reader"
```

同时在另一个窗口把**探针日志**一起抓到（若前缀不同，用 grep 过滤）：

```bash
"$HDC" -t $T shell "hilog -x" | grep -E "PROBE|save pos|place|保存进度被拦|restore pos"
```

> 要的是**从"进阅读页"到"退出"的完整片段**，因为判定靠的是**三条日志的相对时序**，不是单条内容。

**■ 五、判据表（照着读日志，填结论）**

| 观察到的现象 | 判定 | 对应修复 |
|---|---|---|
| **同一屏滚动内 `ratio` 出现多个不同值**，且 `off`/`idx` 非单调 | **RC-1 成立**（结构性根因，不是偶发） | FIX-002（+ FIX-003 提精度） |
| 跳动时间点落在 `place attempt` **仍在增长**期间 | 落位换算在改写状态 | FIX-001 的 G4 + FIX-003 |
| 跳动时间点落在**停手后约 8 秒**（节流落库时刻） | 节流把中间态写库 | FIX-001 的 G1 / G3 |
| 出现 `保存进度被拦：原因…`，但库里的值**仍然变了** | 有绕过自检的写库路径 | FIX-001（G1~G4 全覆盖） |
| 出现 `jumped == 1` 且 `off == ch.start` 且 `userScrolled=false` | 命中**已知缺口**（只拦 >1 章） | FIX-001 的 G3（≥1 章也拦） |
| `userScrolled` 在滚动后**仍为 false**（或反过来一直 true） | RC-3 成立 | FIX-001 的 G2 |
| `ratio` 全程稳定、`off` 也单调，但退出重进**仍跳** | 问题在**落库/恢复**侧，不在推导侧 | FIX-001 优先，FIX-002 可放缓 |
