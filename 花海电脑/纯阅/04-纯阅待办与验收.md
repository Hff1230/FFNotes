### 待办 2 的已知缺口（实机日志证据）

```
20:33:53  打开 → restore pos: 按偏移 | idx=1 ch="第一章 山边小村" off=230     ← 位置是对的
20:33:56  save pos: off=4013 ch=2/2448 title="第二章 青牛镇"                ← 3 秒后自己推进了一章（4013=第二章开头）
20:33:59  按 home（Ability onBackground）
20:35:01  再打开 → restore pos: idx=2 off=4013  ⇒ 停在第二章（用户没读到那）
```

**根因**：保存自检只拦「跳章 >1 章」，**跳 1 章放行**；打开瞬间位置被推进一步（布局/落位未完成时按滚动位置推出章号）后，退出就把这个伪位置存了。
**修法（三条硬闸）**：
1. 自打开以来**无任何用户交互**（`userTouched=false`）期间，`saveProgress()` 直接 return（只写日志）；
2. 无用户交互期间**不许因滚动推导改 `curIndex`**（只有真人滚过/翻过才认）；
3. 跳 **1 章**也要拦：`!userScrolled && jumped >= 1` 且偏移≈新章开头（`off == ch.start`）→ 判伪值丢弃。

## 二、验收清单（每项都必须有判据，不接受"看起来好了"）

### 装书（装载）
- 做法：点开 37MB 的《剑来》（首次装载）与 21.9MB 的《凡人修仙传》（有索引缓存）
- 看什么：屏幕上「正在装书 N%」是否在动；`hilog -x -T reader`
- 判据：① 百分比出现中间值（实测看到 **21%**）；② 日志出现**每片一次**的 `normalize … (775441 → 775440)`（老路是整本一次）；③ 21.9MB 书 ≤3 秒进阅读页
- 现状：✅ 2026-10-14 已过

### 备份到文档
- 做法：长按书 → 备份到文档 → 选位置保存
- 判据：① 文档里文件大小 = 21.9MB / 37MB（**不是 0B**）；② `hilog` 有 `backup ok: N bytes → file://…`；③ 人为失败时不留 0B 残留
- 现状：⚠️ 修复已装（解包验证过含 `copyFileToUri`），**待重启 App 后点一次**

### 阅读进度（核心红线）
- 做法：打开书 → 读几页 → 回桌面（不划掉）→ 重开 App → 进书；再试「从头读 → 立刻退出 → 重开」
- 判据：① 回到上次那一页（误差 ≤1 屏）；② 书架百分比不跳变、不清零；③ `hilog` 无「保存进度被拦」误拦、也无伪位置（`ch` 不该自己 +1）
- 现状：⚠️ 未过

### 翻页纸张效果
- 做法：左右翻页模式，连续翻 5 页；录屏或连拍两帧
- 判据：① 翻页有纸在翻的位移/投影/页缘厚度；② 240ms 内完成、不掉帧；③ 滚屏模式不受影响

### 内存
- 做法：打开 37MB 书，`hidumper --mem <pid>`
- 判据：PSS ≤40MB（现状 148MB）；翻章无卡顿
- 现状：⬜ 未做

### 书源（自用版）
- 判据：搜索/目录/正文三段都能出结果；带 `{{ }}`/JSONPath 的源导入时明确提示不支持；失效检测不误杀 4xx 站点
