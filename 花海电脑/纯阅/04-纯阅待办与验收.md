### 待办 5 的已知缺口（实机日志证据）

```
20:33:53  打开 → restore pos: 按偏移 | idx=1 ch="第一章 山边小村" off=230     ← 位置是对的
20:33:56  save pos: off=4013 ch=2/2448 title="第二章 青牛镇"                ← 3 秒后自己推进了一章（4013=第二章开头）
```

## 二、验收判据（唯一出处；每项都要有判据，不接受"看起来好了"）

### 装书（装载）
- 做法：开 37MB《剑来》（首装）与 21.9MB《凡人修仙传》（有索引缓存）
- 判据：① 「正在装书 N%」出现中间值（实测看到 **21%**）；② 日志出现**每片一次**的 `normalize … (775441 → 775440)`；③ 21.9MB ≤3s 进阅读页
- 现状：✅ 2026-10-14 已过

### 备份到文档
- 做法：长按书 → 备份到文档 → 选位置保存
- 判据：① 文档里文件大小与源文件一致（**不是 0B**）；② 日志有 `backup ok: N bytes → file://…`；③ 重名时保存对话框会提示「已有重名文件」（系统行为）；④ 失败时不留 0B 残留
- 现状：✅ **2026-10-14 模拟器验收通过** —— 38MB 书：`backup ok: 39839962 bytes → file://docs/storage/Users/currentUser/Documents/jianlai.txt`，落盘 39,839,962 字节**逐字节一致**（mtime 12:03）

### 阅读进度（核心红线）
- 做法：打开书 → 读几页 → 回桌面（不划掉）→ 重开 App → 进书；再试「从头读 → 立刻退出 → 重开」
- 判据：① 回到上次位置（误差 ≤1 屏）；② 书架百分比不跳变、不清零；③ 日志**无伪位置**（`ch` 不该自己 +1）、**无误拦**；④ 滚动全程位置**单调**（`save pos:` 不出现反向）
- 现状：⚠️ 未过

### 翻页纸张效果
- 判据：① 翻页有位移/投影/页缘厚度（允许录屏取证）；② 240ms 内完成不掉帧；③ 滚屏模式不受影响；④ **禁止一帧硬切**

### 内存 / 首屏 / 包体
- 内存：`hidumper --mem <pid>` PSS **≤40MB**（现状 148MB）；翻 50 章不单调上涨
- 首屏：点击到出现正文 **≤1.5s**；后台索引完成后位置不跳
- 包体：HAP **≤1.7MB**（现状 1,883,398 B）

### 文本整理（本地书）
- 判据：① **原文未改**：整理前后 **SHA256 完全一致**、文件大小与 mtime 不变；② **正文零丢失**：抽 20 章，原文中"含句末标点的行"**100%** 出现在整理后文本；③ 噪点清零：网址/联系方式/广告话术/分隔线/页码残留 **0**；行内多空格、行尾空白残留 **0**；④ 空行：段落间恰好 1 空行、无连续空行、章首末无空行；⑤ 报告数字与实际 diff 对得上且**幂等**（连跑两次一致）；⑥ 21.9MB 后台整理 ≤1s 且不阻塞首屏

### 文本整理（抓取书）
- 判据：① 抓 100 章后磁盘文本无 HTML 残留、无站点水印、段落规整（抽 20 章）；② **可回溯**：能「另存未整理版」且与 `.raw` 逐字节一致；③ 标题/缺章/卷层级按 01 §2.7

### 目录与结构
- 判据：① 抽检 50 章（跨卷/续章/带前缀）准确 ≥98%；② 跳号书出现「第N章（缺）」且可跳补章；③ 10 本不同编码的书乱码 **0**

### 书源（自用版）
- 判据：搜索/目录/正文三段都能出结果；带 `{{ }}`/JSONPath 的源导入时明确提示不支持；失效检测不误杀 4xx

### 无障碍
- 判据：TalkBack 走查主要路径，无"未命名按钮"
