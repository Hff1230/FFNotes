## 关键事实（照抄，别猜）

- 工程：`E:\HuaweiReader`，真机包名 `com.longxia.huaweireader`
- **两套包**（同一份代码，靠编译期开关区分）：
  - `default`（自用版·带书源）：`ENABLE_BOOK_SOURCE=true`，签名 `default`
  - `gallery`（上架版·无书源）：`ENABLE_BOOK_SOURCE=false`，签名 `releaseSign`
  - 书源相关源码在 `// @@BOOKSOURCE-BEGIN@@ … END@@` 之间，出上架包时由 `tools/build_nosource.py` 摘掉
- **版本号规则（用户口径）**：**未正式上架前一直是 `versionName=1.0.0` / `versionCode=1000000`**；
  上架走应用市场（AGC）时才按 [[02-纯阅工程与架构]] 里的发布流程升版本。
- 语言：11 种（base/de/es/fr/ja/ko/pt/ru/zh_CN/zh_Hant + dark 主题），应用内可切换
- 真机：华为 Pura 70 Pro（HarmonyOS 7），调试走 hdc（见 02 文档）
- 出包机：**花海电脑**（本文件夹所属机器）——后期统一在这台机器上出包

## 工作流（用户指定：文档驱动）

```
① 改文档          需求/规格/口径先写进 01 或 04（一处改，别留两套说法）
        ↓
② 按文档改代码     虾米依据文档生成/修改代码（E:\HuaweiReader），不许偏离文档
        ↓
③ 编译 + 装真机    hvigorw assembleHap → hdc install -r（命令见 02）
        ↓
④ 真机验收        按 04 的验收清单逐条验（有判据/看日志，不许"看起来好了"）
        ↓
⑤ 回写文档        验收结果、改动记录、版本记录写回 04；口径变化就地更新 01/03
```

**铁律**：不先改文档就不许改代码；文档里没写的口径，代码里不许自创。

## 纯阅的三条红线（用户明确要求）

1. **任何情况下不许损坏阅读进度**——保存前必须自检，伪值宁可不写库（见 [[03-纯阅关键约定与踩坑]]）
2. **不用别人的公司资料/资质/证件**（与广告部业务线共用的一条红线）
3. **绿色纯净**：不申请存储权限、不联网上传用户数据；上架版连书源功能都要摘掉
