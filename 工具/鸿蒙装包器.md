**▍ 三、怎么用（四种方式）**

1. **拖 `.hap` 到桌面「鸿蒙装包器」图标上** —— 直接开装，装完自动关。
2. **双击图标** —— 打开窗口，把 `.hap` 拖进窗口，或点击拖放区选择文件。
3. **命令行装包**：
   `powershell -NoProfile -ExecutionPolicy Bypass -File D:/Tools/HapInstaller/hap_installer.ps1 -Hap "C:/路径/xxx.hap" -NoGui`
4. **命令行只取 UDID（不装包）**：
   `powershell -NoProfile -ExecutionPolicy Bypass -File D:/Tools/HapInstaller/hap_installer.ps1 -NoGui -Udid`
   每台设备一行 `SN <Tab> 型号 <Tab> UDID`；无设备退出码 2，全部取失败 3，没找到 hdc 1。

窗口能力：自动列出已连设备（SN · 型号 · 系统，已滤掉 COM1/UART 伪设备与离线设备）、**自动读取该机 UDID 显示在设备行下方**（配「获取 UDID」重取 / 「复制 UDID」进剪贴板）、日志区输出 hdc 原始回显、装完自动 `bm dump` 核验设备端版本、底部彩色状态行（蓝=进行中 / 绿=成功 / 红=失败）。

**▍ 六、实现要点与踩坑**

1. **hdc 传绝对路径会被拼上进程 cwd**：`hdc install "C:/a/b.hap"` 变成 `C:\当前目录\C:/a/b.hap` → `Error opening file`。必须**先切 cwd 再传相对文件名**。
2. **PowerShell 子进程 CWD 的坑（关键）**：PowerShell 启动原生程序时用 **PowerShell 的 location** 作为子进程 CWD；`[System.IO.Directory]::SetCurrentDirectory()` 会被它覆盖 → 必须用 `Push-Location` / `Pop-Location`。
3. **PS 5.1 读无 BOM 的 `.ps1` 会把中文按 ANSI 解**（界面与日志乱码）→ 脚本必须存 **UTF-8 with BOM**。
4. **别跨 runspace 调 UI**：安装跑在独立 runspace（不冻结界面），用 `ConcurrentQueue` + `DispatcherTimer` 回传界面更新；不要传 scriptblock、不要直接摸控件。
5. **`bm dump -n` 的 JSON 前面几个 `versionName` 是空串**，真实版本在后面一组 → 用正则抓 `"versionCode": 数字,"versionName": "字符串"` 的非空匹配。
6. **本机桌面会被 360 托管**到 `D:/360MoveData/Users/<用户>/Desktop`（`C:\Users\<用户>\Desktop` 常是空的）→ 建快捷方式要用 `[Environment]::GetFolderPath('Desktop')`。
7. **取 UDID 只认 `bm get -u`（或 `--udid`）**：`-udid` 报 `error: incorrect option`；`param get const.product.udid` / `persist.sys.udid` 都是 `errNum is:1002`（没这个参数）。解析按整行匹配 `^[0-9A-Fa-f]{32,64}$`，别把错误文本当 UDID 显示。
8. **Offline 状态的设备拿不到 UDID**：`hdc list targets -v` 里 `Offline`（USB 回落「仅充电」）→ `[Fail][E001005] Device not found or connected`；工具只认 `Connected`。
