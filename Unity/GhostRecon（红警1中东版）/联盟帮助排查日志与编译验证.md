```text
MSBuild.exe RedAlertDllProject/RedAlert/RedAlert.csproj -t:Rebuild \
  -p:Configuration=Debug -p:OutputPath="<临时目录>" -p:DebugSymbols=false -p:LangVersion=7.3

退出码 = 0 ；"error CS" 计数 = 0 ；产物 RedAlert.dll = 5 200 896 字节

```

两个必须知道的点：

- **必须显式 `-p:LangVersion=7.3`**：用 VS18 默认语言版本会撞**既有**问题 `Script/Game/UIView/AllianceManor/AllianceBuildingController.cs(45,44): error CS9273`（C＃14 把 `field` 变成属性访问器关键字），与本改动无关；固定 7.3 后 0 错误。
- Debug 配置的默认 `OutputPath` 就是 `..\..\RedAlert\Assets\Code\Framework\Dll\`，即 Unity 真正加载的那份 `RedAlert.dll`；本次为不覆盖线上产物，输出到了临时目录。
- **生效步骤**：按 Debug 配置重编一次 → 自动覆盖 `RedAlert/Assets/Code/Framework/Dll/RedAlert.dll` → Unity 重新加载程序集。

- **未做**：没有把 dll 编进 `Assets/Code/Framework/Dll/`（用 `-p:OutputPath` 避开覆盖），也没有提交 SVN。
