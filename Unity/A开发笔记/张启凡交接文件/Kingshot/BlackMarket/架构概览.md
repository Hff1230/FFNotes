# 黑市系统架构概览

## 系统入口

```
黑市建筑 (BuildID: 724000)
    │
    ▼
KSFunBuild3D_BlackMarket (3D建筑表现)
    │
    ▼
FunBuildPart → BuildUIType.BlackShop
    │
    ▼
KSBlackMarketOrderView (UI视图)
```

---

## 数据流向

```
┌─────────────────────────────────────────────────────────────┐
│                      服务器端                                │
│  kingshoot.blackMarket.operate 协议                         │
└─────────────────────────────────────────────────────────────┘
          ▲                                    │
          │ 网络请求                            │ 网络响应
          │                                    ▼
┌─────────────────────────────────────────────────────────────┐
│                   KSBlackMarketCommand                       │
│  - GetInfo (获取信息)                                        │
│  - Rresh (刷新)                                              │
│  - Sell (出售)                                               │
│  - CheckRefresh (检查刷新)                                   │
│  - Award (领取奖励)                                          │
└─────────────────────────────────────────────────────────────┘
          │                                    ▲
          ▼                                    │
┌─────────────────────────────────────────────────────────────┐
│                  KSBlackMarketManager (单例)                 │
│  - completeOrderCount (已完成订单数)                         │
│  - completeOrderMaxCount (奖励要求数)                        │
│  - receivedRewardCount (已领取奖励进度)                      │
│  - refreshCD (刷新倒计时)                                    │
└─────────────────────────────────────────────────────────────┘
          │                                    ▲
          ▼                                    │
┌─────────────────────────────────────────────────────────────┐
│                    KSBlackMarket (黑市数据)                  │
│  - lv (等级)                                                 │
│  - orders (订单列表)                                         │
│  - remainRefreshCount (剩余刷新次数)                         │
│  - Mode (模式: 1=固定, 2=随机)                               │
└─────────────────────────────────────────────────────────────┘
          │                                    ▲
          ▼                                    │
┌─────────────────────────────────────────────────────────────┐
│                    List<KSOrder> (订单列表)                  │
└─────────────────────────────────────────────────────────────┘
          │                                    ▲
          ▼                                    │

│                      KSOrder (单个订单)                      │

└─────────────────────────────────────────────────────────────┘
          │                                    ▲
          ▼                                    │
┌─────────────────────────────────────────────────────────────┐
│                    KSOrderItem (订单物品)                    │
│  - itemID (物品ID)                                           │
│  - buyCountPerTime (每次购买数量)                            │
│  - requireBuyCount (需要购买总次数)                          │
│  - completeSubmit (剩余购买次数)                             │
│  - rate (价格比率)                                           │
│  + Sell() (出售物品)                                         │
└─────────────────────────────────────────────────────────────┘
```

## UI层级

```
KSBlackMarketOrderView (订单主视图)
├── orderList (GList - 订单列表)
│   └── KSOrderItemCom (订单项组件)
│       ├── kSGoodsItem (物品图标)
│       ├── title (物品名称)
│       ├── num (进度: 已完成/总数)
│       ├── own (拥有数量)
│       ├── money (价格)
│       └── sellBtn (出售按钮)
│           └── c1控制器: [0]可出售 [1]已完成 [2]物品不足
├── totalMoney (总金额)
├── completeOrderSlider (进度条)
├── refreshBtn (刷新按钮) - Mode 2时显示
├── refreshCountText (刷新次数)
└── awardBtn (奖励按钮)
```

## 配置关系

```
KSBlackMarketConfig (按等级配置)
    │
    ├── mode: 1/2 (订单模式)
    ├── maxRefreshCount (最大刷新次数)
    ├── refreshRecoverHours (刷新恢复时间)
    │
    └── orderGroupIDs ──────────────┐
         │ "1,2,3,4|5,6,7,8"        │
         ▼                          ▼
    ┌────────────┐           KSOrderConfig (订单配置)
    │ 订单组1    │              │
    │ 1,2,3,4    │              ├── itemIDs (物品ID列表)
    └────────────┘              ├── rate (价格比率列表)
    ┌────────────┐              ├── requireBuyCount (需要次数)
    │ 订单组2    │              └── buyCountPerTime (每次数量)
    │ 5,6,7,8    │
    └────────────┘
                                  KSOrderReward (奖励配置)
                                      │
                                      ├── sum_count (累计要求)
                                      └── reward (奖励物品ID)
```

## 关键常量

| 常量 | 值 | 说明 |
|-----|---|------|
| `Global.FUN_BUILD_KS_BLACK_MARKET` | 724000 | 黑市建筑ID |
| `BuildUIType.BlackShop` | - | 黑市UI类型 |
| `GoodsLocalType.INBlackMarket` | - | 黑市物品位置标记 |
| `KSDataType.Trade` | - | 任务类型-交易 |

---

## 协议操作码

| 操作 | 说明 |
|-----|------|
| `GetInfo` | 获取黑市信息 |
| `Rresh` | 刷新订单 (注意拼写) |
| `Sell` | 出售物品 |
| `CheckRefresh` | 检查刷新状态 |
| `Award` | 领取奖励 |
