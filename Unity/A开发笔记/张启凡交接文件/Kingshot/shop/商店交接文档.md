# KingShot 商店系统交接文档

## 1. 概述

KingShot 商店系统是一个游戏内商店模块，为玩家提供购买和出售物品的功能。系统基于 **FairyGUI** 框架实现，使用 `PopupBaseView` 作为弹窗基类。

## 3. 系统架构

### 3.1 类图结构

```
KingShotShopView (商店主界面)
├── BackpackComponent (背包组件 - 左侧)
│   └── KSGoodsItem[] (物品格子数组)
│       ├── KSBackPackItem (普通物品显示)
│       └── KSEquipItem (装备物品显示)
│
└── ShopComponent (商店组件 - 右侧)
    └── KSGoodsItem[] (商品格子数组)
        └── 倒计时刷新功能
```

### 3.2 核心类说明

#### KingShotShopView
- **继承**: `PopupBaseView`
- **职责**: 商店主界面，管理背包和商店两个子组件
- **创建方式**: `KingShotShopView.Create()`
- **主要方法**:
  - `InitializeFairyComponents()` - 初始化FairyGUI组件
  - `RefreshUI()` - 刷新整个界面
  - `GenerateDataNew()` - 生成背包数据

#### ShopComponent
- **继承**: `GComponent` (FairyGUI组件)
- **职责**: 显示商店商品列表，管理倒计时刷新
- **主要属性**:
  - `_backPackGList` - 商品列表
  - `refreshText` - 倒计时文本
- **主要方法**:
  - `RefreshBackPack()` - 刷新商品列表
  - `StartCountDown()` - 开始倒计时
  - `RefreshTimeText()` - 更新倒计时显示

#### BackpackComponent
- **继承**: `GComponent` (FairyGUI组件)
- **职责**: 显示玩家背包物品
- **主要方法**:
  - `RefreshBackPack()` - 刷新背包列表
  - `SaveAllToWareHouse()` - 全部存入仓库
  - `TidyBackpack()` - 整理背包

## 6. 核心流程

### 6.1 商店打开流程

```
1. 调用 KingShotShopView.Create()
2. PopupViewController 创建视图实例
3. InitializeFairyComponents() 初始化组件
   ├── 获取 BackpackComponent (n31)
   ├── 获取 ShopComponent (n30)
   └── 设置拖拽事件
4. Init() 初始化数据
   ├── GenerateDataNew() 生成背包数据
   ├── backComponent.ScrollTop() 滚动到顶部
   └── RefreshUI() 刷新界面
5. ShopComponent 初始化
   ├── 获取商店信息 (KSShopManager.GetShopInfo)
   ├── 开始倒计时 (StartCountDown)
   └── 刷新商品列表 (RefreshBackPack)
```

### 6.2 购买流程

```
1. 玩家点击商品格子
2. 打开 KSSellEquDetailComponent 详情弹窗
3. 玩家选择购买数量
4. 点击购买按钮
5. 调用 BuyOnClick()
   ├── 检查背包空间
   ├── 检查金币是否足够
   ├── 创建物品 KSGoodsController.CreateGoods()
   └── 发送网络命令 KSGoodsOperateCommand
6. 服务器返回成功
7. 刷新商店UI (RERESHKingShotShopView 通知)
```

### 6.3 出售流程

```
1. 玩家双击背包物品
2. 打开 KSSellEquDetailComponent 详情弹窗
3. 显示出售价格（原价 * 折扣率）
4. 玩家选择出售数量
5. 点击出售按钮
6. 调用 SellOnClick()
   └── 发送网络命令 KSGoodsOperateCommand
7. 服务器返回成功
8. 刷新商店UI
```

### 6.4 倒计时刷新流程

```
1. ShopComponent.ConstructFromXML() 初始化
2. 调用 KSShopManager.GetShopInfo() 获取刷新时间
3. StartCountDown() 开始倒计时
4. Update() 每帧检查
   ├── 计算剩余时间
   ├── 更新倒计时文本
   └── 时间到期时自动刷新商店
5. 时间到期
   ├── 重新获取商店信息
   ├── 刷新商品列表
   └── 重新开始倒计时
```

### 7.3 倒计时更新

```csharp
private void RefreshTimeText()
{
    TimeSpan remaining = targetTime - DateTime.Now;
    if (remaining.TotalSeconds <= 0)
    {
        isCountingDown = false;
        // 刷新商店
        KSShopManager.Instance.GetShopInfo((shopInfo) =>
        {
            Global.POST_SAFE_NOTIFY(KingShotShopView.RERESHKingShotShopView, null);
            StartCountDown(shopInfo.RefreshTime.Hours, shopInfo.RefreshTime.Minutes, shopInfo.RefreshTime.Seconds);
        });
        return;
    }
    string timeInfo = string.Format("{0:D2}:{1:D2}:{2:D2}", remaining.Hours, remaining.Minutes, remaining.Seconds);
    refreshText.text = Global._lang_1("2000010252", timeInfo);
}
```

### 7.4 价格计算

```csharp
public int GetBuyMoney()
{
    var good = DataAtlasManager.Instance.GetDataWithTypeById<KSGoodsConfig>(this.id);
    float price = (float)good.cost;
    return Mathf.FloorToInt(buyRate * price);  // 原价 * 加价率
}

public int GetSellMoney()
{
    var good = DataAtlasManager.Instance.GetDataWithTypeById<KSGoodsConfig>(this.id);
    float price = (float)good.cost;
    return Mathf.FloorToInt(sellRate * price);  // 原价 * 折扣率
}
```

## 10. 注意事项

1. **背包容量检查**: 购买前需检查背包剩余空间
2. **金币检查**: 购买前需检查玩家金币是否足够
3. **已售罄商品**: `capacity == 0` 时显示灰色并标记已售罄
4. **倒计时自动刷新**: 商店会定时自动刷新商品
5. **本地/服务器模式**: 通过 `ArchivedData.Instance.LocalRecord` 判断
6. **黑市商店**: 目前暂未完整实现（策划说暂时先不做）
