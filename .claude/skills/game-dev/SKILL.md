# 游戏开发技能

帮助开发HTML5小游戏的专家技能，专注于麻将、扑克、棋牌等类型的浏览器游戏。

## 快速开始

1. 确认游戏类型和核心玩法
2. 选择技术方案（纯前端/局域网联机/服务器版）
3. 开始实现游戏逻辑

## 游戏类型

### 棋牌游戏
- **麻将**：桐城自摸、血战到底、四川麻将等
- **扑克**：掼蛋、斗地主、德州扑克、炸金花等
- **其他**：象棋、围棋、五子棋等

### 技术方案

| 方案 | 适用场景 | 技术栈 |
|------|----------|--------|
| 纯前端 | 单机游戏、本地多人 | HTML + CSS + JS |
| 局域网联机 | 家庭/办公室多人 | WebSocket + Node.js |
| 服务器版 | 互联网多人 | Socket.io + 数据库 |

## 开发流程

### 步骤 1：需求分析
- 确定游戏规则和特殊玩法
- 确定玩家数量和交互方式
- 确定是否需要AI对手

### 步骤 2：界面设计
- 游戏桌面布局
- 卡牌/麻将牌样式
- 玩家位置和交互按钮
- 动画效果

### 步骤 3：核心逻辑
- 游戏状态管理
- 牌型判断算法
- 回合流程控制
- 胜负判定

### 步骤 4：网络功能（如需要）
- WebSocket 通信
- 房间管理
- 玩家状态同步
- 断线重连处理

## 代码规范

### 文件组织
```
game-name/
├── index.html        # 主页面
├── game.js          # 游戏逻辑
├── server.js        # 服务器（如需要）
├── styles.css       # 样式（可内联）
└── README.md        # 使用说明
```

### 命名约定
- 函数：驼峰命名 `calculateScore()`
- 常量：大写下划线 `MAX_PLAYERS`
- CSS类：短横线命名 `.player-hand`

### 样式风格
- 使用渐变背景营造游戏氛围
- 金色/绿色主题适合棋牌游戏
- 按钮要有明显的悬停和点击效果

### 洗牌算法
```javascript
function shuffle(array) {
    for (let i = array.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [array[i], array[j]] = [array[j], array[i]];
    }
    return array;
}
```
