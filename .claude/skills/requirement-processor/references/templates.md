## 3. API接口规范 (api-spec)

```markdown
# [API名称] - API接口规范

## 基本信息
| 项目 | 内容 |
|------|------|
| API路径 | /api/v1/[resource] |
| 请求方法 | GET/POST/PUT/DELETE |
| 认证方式 | Token/Session/None |

## 请求参数

### Headers
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | string | 是 | 认证令牌 |

### Query Parameters (GET)
| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| [参数1] | string | 是 | [说明] | [示例] |

### Request Body (POST/PUT)
```json
{
  "field1": "value1",
  "field2": "value2"
}
```

## 响应格式

### 成功响应 (200)
```json
{
  "code": 0,
  "message": "success",
  "data": {
    // 响应数据
  }
}
```

### 错误响应
| 状态码 | 错误码 | 说明 |
|--------|--------|------|
| 400 | INVALID_PARAM | 参数错误 |
| 401 | UNAUTHORIZED | 未授权 |
| 404 | NOT_FOUND | 资源不存在 |

## 示例

### 请求示例
```bash
curl -X GET "https://api.example.com/api/v1/resource" \
  -H "Authorization: Bearer token"
```

### 响应示例
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "name": "example"
  }
}
```

## 变更记录
| 日期 | 版本 | 变更内容 |
|------|------|----------|
| YYYY-MM-DD | v1.0 | 初始版本 |
```
